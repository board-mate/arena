# v11.4.80 — 홈 공지·일정·Instagram

## 화면 변경

- 홈 상단에 BoardMate Note의 최신 공지 제목과 공지 전체 보기 버튼을 표시합니다.
- 월 달력에서 일정 날짜를 표시하고, 날짜 선택 및 날짜 hover로 일정 제목/시간/장소를 보여줍니다.
- 예정 일정 전체 보기 대화상자를 추가했습니다.
- 공지와 일정 화면은 읽기 전용입니다. 등록/수정/삭제 폼과 Note 편집 페이지 링크를 제공하지 않습니다.
- `@board__mate`의 확인된 최근 Instagram 게시물 요약 카드와 최신 게시물을 확인하는 프로필 링크를 추가했습니다.

## 공개 데이터 범위

- `announcements`: 공지 표시를 위한 제목, 본문, 고정 여부, 생성/수정 일시만 조회.
- `schedules`: 일정 표시를 위한 제목, 날짜, 시간, 장소, 메모만 조회.
- 모임 기록 테이블은 읽지 않습니다.
- 앱은 읽기 전용 `SELECT` 요청만 보냅니다. 신규 Supabase SQL/RPC는 없습니다.
- Instagram 프로필 임베드는 현재 홈 내부 프레임에서 빈 화면을 반환해 쓰지 않았습니다. 요약 문구는 2026-09-28에 확인한 최신 게시물을 반영하며, Instagram 프로필 링크는 현재 최신 글로 이동합니다. 새 게시물 이후 요약 문구를 갱신해야 합니다.

## 확인 항목

- `node --check app.js`, `node --check multi-common.js`, `node --check sw.js`: 통과.
- 실제 브라우저에서 공지 읽기 전용 창과 2026-10-02 일정 선택을 확인했습니다.
- 공개 Note 데이터 연결 시 공지 목록은 비어 있고, 10월 2일/8일/18일 일정 표시를 확인했습니다.
- 브라우저 화면의 Instagram 프로필 iframe/공식 embed.js 피드 렌더링은 실패해 텍스트 요약 카드로 전환했습니다.
- 외부 배포는 하지 않았습니다.

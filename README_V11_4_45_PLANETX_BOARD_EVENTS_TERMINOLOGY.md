# BoardMate Arena v11.4.45 · 행성 X 원형 보드 이벤트/명칭 정리

## 변경 사항

- 원형 태양계 보드 바깥쪽에 **학술제**와 **회의** 발생 지점을 직접 표시합니다.
  - 표준: 학술제 3 / 6 / 9 / 12, 회의 X1 = 10
  - 전문가: 학술제 3 / 6 / 9 / 12 / 15 / 18, 회의 X1 = 8, X2 = 16
- 원형 보드 바로 아래에도 같은 일정을 텍스트 배지로 표시해 모바일에서도 시점을 쉽게 확인할 수 있습니다.
- 사용자 화면의 `가설` 명칭을 모두 `논문`으로 변경했습니다. 내부 DB/RPC의 `theory` 식별자는 호환성을 위해 그대로 유지합니다.
- 이전 버전에서 저장된 공개 기록에 `가설` 문구가 남아 있어도 화면에는 `논문`으로 보이도록 표시 단계에서 변환합니다.
- `약자(기록용): A/C/D/G/E/X` 범례를 제거했습니다.
- `참조표`를 오른쪽 사이드바에서 빼고 게임 화면의 **가장 아래 전체 폭 영역**으로 이동했습니다.
- 게임 로직과 Supabase 스키마 변경은 없습니다.

## 배포

1. `online-planetx.html`, `sw.js`, `index.html`, `HANDOFF_VERSION.txt`를 GitHub Pages 저장소에 덮어씁니다.
2. 이번 버전에는 새 SQL이 없습니다.
3. 배포 후 브라우저에서 강력 새로고침합니다. 서비스워커 캐시는 `v11.4.45`로 갱신됩니다.

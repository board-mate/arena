# 정식 플레이 게임 14종 점검 — 2026-10-30

대상은 `app.js`의 `gameInfo`에서 `tier`가 없는 다인플 게임 14종이다. 알파·베타 게임과 솔로 메뉴는 이번 점검 대상에서 제외했다.

## 새로 확인하고 수정한 문제

### 판타지 왕국 2인전

기존 구현은 인원과 관계없이 7장씩 나눠 주고 버린 카드 10장으로 종료했다. 새로운 2인 게임은 공식 2인 변형을 적용한다.

- 빈 손으로 시작한다.
- 손패가 7장 미만이면 덱에서 2장을 뽑고 1장을 버리거나, 버린 카드 1장만 가져와 차례를 마친다.
- 손패 7장에 도달한 플레이어는 기본 턴 규칙으로 전환한다.
- 두 플레이어 모두 7장이고 버린 카드가 12장 이상일 때 종료한다.
- 화면 안내와 종료 카운터도 해당 규칙에 맞게 표시한다.
- 공개 저장 상태의 `twoPlayerVariant`가 컨트롤러 복구 후에도 유지된다. 기존 진행 방은 이 표시가 없으므로 기존 규칙을 유지한다. 새 3–6인 게임은 기존 규칙을 유지한다.

### 어콰이어

다음 플레이어의 손패에 배치 가능한 타일이 없으면 손패 전체를 폐기하고 주머니에서 교체하던 오류를 수정했다. 일시적으로 새로운 체인을 설립할 수 없는 타일은 보관해야 한다. 이제 손패와 주머니를 유지하고 해당 차례의 주식 구매 단계로 넘어간다. 영구 배치 불가 타일의 기존 교체 처리는 별도다.

DB 함수·스키마 변경은 없다. 과거 게임 상태를 소급 수정하지 않는다.

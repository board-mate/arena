# BoardMate Arena v11.4.38 — 행성 X 플레이 UI 보강

## 변경 1 · 연구 주제 제목 표시

기존 UI는 `A / B / C / D / E / F`만 보여 주어 어떤 천체 관계를 연구하는지 선택 전에 알 수 없었습니다.

v11.4.38에서는 게임별 공개 주제 제목을 별도 RPC로 받아 다음처럼 표시합니다.

- `A · 왜소행성 · 혜성`
- `B · 가스 구름`
- `C · 소행성 · 혜성`

실제 제목은 선택된 게임 코드에 따라 달라집니다. 제목은 공개 정보지만, 해당 주제의 논리 규칙은 기존처럼 연구 실행 후 연구한 플레이어에게만 반환됩니다.

공개 행동 기록에도 `주제 A (왜소행성 · 혜성) 조사`처럼 제목을 함께 남깁니다.

## 변경 2 · 혜성 기록 버튼 제한

천문학 노트의 섹터 메모에서 혜성 버튼은 혜성이 규칙상 존재할 수 있는 섹터에만 표시합니다.

- 표준 12섹터: `2, 3, 5, 7, 11`
- 전문가 18섹터: `2, 3, 5, 7, 11, 13, 17`

혜성 가능 섹터는 `🌠 혜성 가능` 라벨과 별도 테두리로 구분됩니다. 다른 섹터의 기존 로컬 메모 데이터가 있더라도 삭제하지 않고 UI에서만 혜성 버튼을 숨깁니다.

## 변경 3 · 원형 태양계 / 맞은편 표시

기존 직사각형 상세 섹터 카드는 가설 토큰과 확인 정보를 보기 편하지만 `정반대편` 관계를 직관적으로 읽기 어려웠습니다.

그래서 상세 보드는 유지하고 그 위에 원형 방향판을 추가했습니다.

- 섹터 번호를 실제 원 둘레에 시계 방향으로 배치
- 청록색: 현재 관찰 가능 하늘
- 금색 외곽선: 현재 지구 기준 섹터
- 확인된 섹터: 확인 개체 약어 표시
- 각 원형 번호 아래 `↔ 맞은편 번호` 표시
- 상세 섹터 카드에도 `↔ 맞은편 N` 표시

정반대 계산:

- 표준 12섹터: `+6` (`1↔7`, `2↔8`, ...)
- 전문가 18섹터: `+9` (`1↔10`, `2↔11`, ...)

따라서 “어떤 소행성도 왜소행성의 정반대편에 있지 않습니다” 같은 연구/회의 힌트를 화면만 보고 바로 적용할 수 있습니다.

## Supabase

기존 v11.4.34~v11.4.37 설치자는 아래 파일을 1회 실행합니다.

`SUPABASE_PLANETX_RESEARCH_TOPICS_V2.sql`

새 설치에서 `SUPABASE_PLANETX_PVP_V1.sql`을 실행하는 경우에는 같은 RPC가 전체 설치 SQL에도 포함되어 있습니다.

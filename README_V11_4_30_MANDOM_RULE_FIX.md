# BoardMate Arena v11.4.30 — 맨덤의 던전 규칙 복구

기준: v11.4.29 GAME FIXES. 다른 게임 파일은 변경하지 않음.

## 맨덤의 던전 흐름
1. 플레이어끼리 행동 순서를 정하고 방장이 순서를 설정한다.
2. 자신의 턴에 다음 3가지 중 하나만 선택한다.
   - 몬스터 카드를 뽑아 자신만 확인 → 던전에 놓기
   - 몬스터 카드를 뽑아 자신만 확인 → 자기 앞에 가져가고 장비 토큰 1개 획득
   - 패스
3. 다른 플레이어가 모두 패스하여 1명만 남으면 그 플레이어가 용사가 된다.
4. 용사는 주어진 장비로 던전의 몬스터를 순서대로 공략한다.
5. 던전 성공 → 승리 토큰 +1.
6. 던전 실패 → 해당 용사의 몬스터 목록 카드가 빨간 테두리 상태가 된다.
7. 빨간 테두리 상태에서 다시 실패 → 해당 플레이어 탈락.

## 용사의 검
- 번호가 붙은 같은 종류의 몬스터를 개별 카드로 보지 않고 '종류'로 묶는다.
- 예: 골렘을 선언하면 `골렘 ①`과 `골렘 ②` 모두 용사의 검으로 무력화된다.
- 기존 저장 게임에 `namedMonster=golem1` 또는 `golem2`가 있어도 같은 종류 전체 판정으로 처리한다.
- 선언 UI도 골렘 ①/②를 따로 보여주지 않고 '골렘' 한 항목으로 보여준다.

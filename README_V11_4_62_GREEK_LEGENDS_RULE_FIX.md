# BoardMate Arena v11.4.62 · Fantasy Realms: Greek Legends Rules Fix

## 적용 내용
- `fantasyrealmsgreek` 게임 등록 및 3~6인 방 생성 지원
- 공식 룰북 기준 사후세계 즉시 효과 구현
  - 모이라이(운명), 코르누코피아, 델포이의 신탁, 희생제단
  - 사후세계로 버릴 때 매 턴 중앙 버리는 공간에 최소 1장이 추가되는 규칙 반영
- 공식 엔드게임 순서 구현
  1. 선택적 보너스 CLEAR (몰리, 마법 고삐)
  2. 필수 페널티 CLEAR (연꽃 자생지, 키르케, 디오니소스)
  3. 선택적 태그 ADD (아테나, 케이론, 날개 달린 샌들)
  4. Ω 카드 순차 처리 (적대적 몬스터, 헤라클레스, 석류)
- 몬스터와 영웅의 맞서는 순서를 반영하여 조건을 만족하는 영웅이 나오기 전 비조건 영웅을 사후세계로 보낼 수 있도록 구현
- 하데스의 투구 1회 생존 보호 선택 구현
- 점수 엔진 수정
  - 레테강: 사후세계 영웅의 보너스/태그 무시
  - 히드라: '한 명의 살아 있는 영웅이 서로 다른 태그 3개 이상' 조건으로 수정
  - 세이렌: 현명함이 아니라 영악함(CLEVER) 조건으로 수정
  - 이아손: 자신이 사후세계에 있을 때 살아 있는 영웅 수 계산 수정
  - 페르세포네: 자신을 제외한 사후세계/식물 쌍 계산 수정
  - 신격화: 살아 있는 영웅만이 아니라 영웅(손패 또는 사후세계) 요구로 수정
  - 디오니소스 프로모의 CLEAR/기본점수 보너스 처리
- GitHub Pages 캐시 키를 `v11.4.62`로 갱신

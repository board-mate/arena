# v11.4.89 솔로 규칙 오류 수정

실물 기본판 전체 교체가 완료된 릴리스가 아니다. 원본 카드 수치가 없는 부분에 새 수치를 추정하여 추가하지 않았다. BGA 및 로그인 필요한 외부 게임은 추가하지 않았으며, 솔로 캘리코/캐스캐디아 파일은 변경하지 않았다.

## 수정

- 콘세르바스: 공식 1월 시장 24칸과 보상으로 교체. 첫 보트 선택에서 남은 카드가 덱 아래로 돌아감. 보조 그물은 첫 뽑기에만 선택적으로 8개를 뽑고 3개를 반환. 정비 창고 비용/할인 수정. 공급 카드 교체 선택과 별도 버림 더미. 플레이어가 유지비 납부 순서를 정함. 못 내는 보트는 돈을 쓰지 않고 버리며, 그 아래 바다 토큰은 보존하여 번식. 비공개 주머니 내용 숨김. 어획물 없는 무료 업그레이드 구매 차단.
- 에친스톤: 공격과 이동을 독립 계산, 일치하는 강화 이동의 예비 카드 보너스, 느림 적에게 이동 비교 및 증폭 선택. 원거리 무시 후에도 일반 선제권 비교. 원거리/빙결의 예비 카드 폐기는 피해/향상 이후 정리 단계. 우회 시 다음 조우를 잘못 생략하던 조건 수정. 재정비는 기존 덱 순서를 유지하고 손패만 섞어 아래에 둠. 마지막 전투의 조합별 선제권 증폭 및 필수 역할 수 검증.
- 커피 로스터: 요구되는 동일 플레이버 여러 개를 개별 계산. 단맛이 별도 요구되지 않으면 빠진 플레이버를 대체. 요구와 다른 플레이버라도 존재하면 플레이버 부재 감점 없음. 원두 구성 합계 표시를 실제 목록에서 계산.

## 저장

콘세르바스의 16칸 프로토타입 저장은 24칸 시장으로 매핑할 수 없어 새 키 `boardmate:solo:conservas:v2`를 사용한다. 기존 v1 저장은 삭제하지 않지만 이 버전에서 이어하지 않는다. 나머지 저장은 기존 키를 사용한다. DB/SQL 변경 없음.

- [Dragons of Etchinstone 제작사 규칙 페이지](https://chiptheorygames.com/pages/support/dragons-of-etchinstone), 연결된 기본판 rulebook v1.0 및 [출판사 검증 Dized 규칙](https://rules.dized.com/game/CskMrsIiT4S_UgD5seCOUQ/dragons-of-etchinstone).
- [Coffee Roaster 공식 규칙서](https://cdn02.plentyone.com/9gjbo7zbn9p8/frontend/Spiele/Spielregeln/Coffee_Roaster_EN.pdf), 채점 pp. 14–16.

## 검증 및 남은 작업

`tests/solo-rules.test.cjs`는 수정된 판정과 토큰/현금 보존을 실행한다. 전체 게임 HTML의 구문/자산 검사와 기존 이벤트/알림/캘리코 테스트도 실행한다. 여러 계정의 모든 게임 완주, 모든 카드 효과 및 모든 기본판 구성 검증을 의미하지 않는다.

- 콘세르바스: 전체 보트 18장, 업그레이드 27장, 2–12월 시장 자료 미확보. 기존 자체 카드가 남아 있다. 업그레이드별 선택/타이밍도 전체 교체가 필요하다.
- 에친스톤: 16장 마법사의 각 레벨, 4개 지역, 4마리 용의 전체 원본 값 미확보. 기존 공식에서 임의 생성한 값이 남아 있다. 융합 UI 및 중독/지역 경계의 추가 대조도 남아 있다.
- 커피 로스터: 22종 원두의 모든 구성/요구 플레이버/점수표 원본 대조 미완료. 현재 대부분 요구 플레이버가 공통 배열로 되어 있어 원본 카드 자료가 필요하다.
- 나머지 게임: v88의 시작 화면/구문 검증 외에 전체 규칙 검증은 미완료. 기존 점검 문서의 PASS는 해당 테스트 범위만 뜻한다.

공개 공식 규칙서는 확보했지만 위 전체 구성은 포함하지 않는다. 사용자는 컴퓨터에 원본 카드 자료가 없다고 확인했다. 이 자료 없이 실물 기본판과 동일하다고 표시하면 안 된다.

# BoardMate Arena v11.4.25 — 1인플 저장 / 게임 포기

## 적용 대상
BoardMate 저장 지원: Acquire, 에친스톤의 용들, 마스크맨, The Game, 커피 로스터, 포켓몬 미니마(포켓노바 리다이렉트 포함).

## 동작
- 게임 중 우측 하단에 `💾 저장`, `🏳 게임 포기`가 표시됩니다.
- 지원 게임은 주기적 자동 저장 + 페이지 이탈/백그라운드 전환 시 저장을 수행합니다.
- `게임 포기`는 확인 후 해당 게임 저장 데이터를 삭제하고 초기 화면/새 게임 상태로 돌아갑니다.
- 커피 로스터와 포켓몬 미니마는 이번 버전부터 진행 상태 자동 복원까지 지원합니다.
- 기존 저장이 있던 Acquire/에친스톤/마스크맨/The Game은 기존 저장 키를 유지해 이전 저장본과 호환됩니다.

## 외부 게임 예외
캘리코와 캐스캐디아는 다른 도메인의 웹사이트를 iframe으로 표시합니다. 브라우저의 Same-Origin Policy 때문에 BoardMate가 해당 iframe의 localStorage/게임 객체에 접근하여 저장하거나 삭제할 수 없습니다. 따라서 해당 게임의 저장 여부는 외부 사이트 구현에 따릅니다.

# BoardMate Arena v11.4.39 — 행성 X 게임판 중심 배치

## 목적

실물 행성 X 보드처럼 **원형 보드를 중심으로 게임 상태, 가설, 플레이어 위치와 개인 조사 결과를 가까운 곳에서 확인**할 수 있도록 화면을 재배치했습니다.

## 변경 1 · 내 비공개 조사 기록을 게임판 바로 아래로

기존에는 `내 천문학 노트`의 맨 아래에 조사 기록이 있어 섹터 메모가 길어질수록 결과를 확인하려고 많이 내려가야 했습니다.

v11.4.39에서는 원형 게임판 바로 아래에 `🔒 내 비공개 조사 기록`을 별도 표시합니다.

- 개체 탐사
- 섹터 지정 조사
- 주제 조사
- 행성 X 찾기 시도

결과가 최신순으로 즉시 쌓입니다. 최대 높이를 제한한 내부 스크롤 영역이라 페이지 전체가 길어지지 않습니다.

## 변경 2 · 개인 기록지를 우측 상단으로

데스크톱에서는 `현재 진행` 바로 아래에 `🔒 내 기록지`가 배치됩니다.

- 시작 정보
- 섹터별 후보 메모
- 혜성 가능 섹터 표시

참조표, 공개 회의 정보, 공개 기록보다 먼저 보입니다.

## 변경 3 · 원형 보드를 실물 보드에 가깝게

원형 보드에 다음 시각 요소를 추가했습니다.

- 섹터별 방사형 경계선
- 중앙 태양
- 현재 관찰 가능 섹터 강조
- 지구 기준 섹터 금색 강조
- 각 섹터의 정반대 번호
- 플레이어 시간 위치를 색 점으로 표시
- 가설을 작은 사각형 토큰으로 표시
- 확인된 개체 약어 표시

따라서 별도 상세 카드로 내려가지 않아도 게임판에서 상당수 상태를 읽을 수 있습니다.

## 변경 4 · 상세 섹터는 접어서 보조 정보로

기존 직사각형 섹터 상세 보드는 삭제하지 않았습니다. `🧩 섹터 상세 · 가설 트랙`을 눌러 펼칠 수 있게 해 원형 게임판이 메인 화면을 차지하도록 했습니다.

## 스크롤 / 저장 호환성

- 자동 상태 갱신 시 `captureScroll()` / `restoreScroll()` 유지
- 개인 기록은 기존 localStorage 키/구조 그대로 사용
- 진행 중인 행성 X 방 상태 JSON 구조 변경 없음
- v11.4.38 DB와 호환

## Supabase

**v11.4.39 자체에는 새 SQL이 없습니다.**

v11.4.38 SQL을 이미 적용한 설치는 HTML 파일만 교체해도 행성 X 변경 사항이 동작합니다.

# BoardMate Arena v11.4.34 — 행성 X를 찾아서 완전 PVP

기준본: **BoardMate Arena v11.4.33 FULL**

이번 버전은 기존 `online-planetx.html` 보조 도구가 아니라, BoardMate 방 안에서 2~4명이 실제 게임 전체 흐름을 끝까지 진행하는 **온라인 PVP 구현**입니다.

## 구현 범위

- 표준 12섹터 / 전문가 18섹터
- Supabase 서버에서 숨은 태양계 게임을 선택하고 정답은 클라이언트 공개 상태에 저장하지 않음
- GM Kit 100게임(표준 50 / 전문가 50) 서버 카탈로그 포함
- 각 플레이어별 춘분/하지/추분/동지 시작 정보 + 유스/초보자/경험자/천재 난이도
- 관찰 가능한 하늘 자동 계산
- 타임 트랙과 가장 뒤처진 플레이어의 다음 턴 자동 처리
- 개체 탐사 / 섹터 지정 / 주제 조사 / 행성 X 찾기
- 행성 X가 탐사/섹터 지정에서 `비어 보임`으로 처리
- 섹터 지정 토큰 2회 제한
- 연구 연속 사용 금지
- 회의 X1 / 전문가 X2
- 가설 단계: 동시 비공개 선택 → 플레이어 순서대로 뒷면 배치 → 트랙 전진
- 교차 검증, 틀린 가설 시간 +1 패널티, 섹터 확정
- 행성 X 발견 뒤 마지막 점수 기회
- 정답 공개 및 최종 점수 자동 계산
- 리더 보너스 / 개체별 가설 점수 / 행성 X 점수 / 공식 타이브레이커
- 완전 동점은 공동 승리로 표시하며 ELO 자동 반영을 생략
- 개인 추리 노트는 브라우저 로컬에만 저장
- 공개 게임 상태는 기존 BoardMate Realtime + polling 동기화 사용
- 기존 전체 동의 게임 취소 UI는 `multi-common.js`를 그대로 사용

## 필수 SQL

GitHub 파일 업로드 후 **Supabase SQL Editor에서 `SUPABASE_PLANETX_PVP_V1.sql`을 한 번 실행해야 합니다.**

이 SQL은 기존 데이터를 삭제하지 않고 다음만 추가/교체합니다.

1. `planetx` 게임 ID를 BoardMate 방/레이팅 카탈로그에 추가
2. 2~4인 방 생성/최소·최대 인원/현재 턴 helper 갱신
3. 행성 X 비공개 GM 카탈로그/세션/가설 테이블 생성
4. GM Kit 100게임 등록
5. 비공개 조사/연구/행성 X 판정 RPC 생성
6. 비공개 가설 선택/배치/교차 검증/최종 공개 RPC 생성
7. 탐사·타겟·연구·Locate에 현재 턴/관찰 하늘 서버 검증 적용

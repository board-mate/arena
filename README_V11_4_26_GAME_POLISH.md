# BoardMate Arena v11.4.26 — 게임 수정

## 이름 / 삭제
- 프라코로 → **프라코로 포켓몬**
- 사무라이 PVP → **사무라이**
- **포켓몬 미니마**: Arena 메뉴와 배포 파일에서 제거. 기존 DB 행과 제약조건 충돌 방지를 위해 legacy game id `pocketnova`만 DB 호환용으로 남김.

## 프라코로 포켓몬
- V5 SQL이 `boardmate_plakoro_setups` 테이블까지 직접 생성하므로 과거 catalog SQL을 실행하지 않았어도 준비 RPC가 동작합니다.
- 첫 화면의 기본 포켓몬을 실제 `setupChoice`로 초기화해 기술 선택이 바로 반응합니다.
- 준비 시작 오류는 `동기화 오류` 한 문구 대신 실제 오류 요약을 표시합니다.

## 엘도라도
- 기본 코스를 13열에서 21열 장거리 코스로 확장했습니다.
- 봉쇄는 전체 맵을 가르는 붉은 점선 `봉쇄선`으로 표시하며 제거 후 녹색/희미한 선으로 바뀝니다.

## 돌팔이 약장수
- 1~34칸 냄비/정산 트랙을 추가했습니다.
- 각 플레이어 정산 위치를 번호 마커로 표시합니다.
- 내 패널에서 현재 남은 주머니와 정산 단계의 `다음 라운드 주머니 전체 구성`을 색/숫자별로 확인할 수 있습니다.

## 맨덤의 던전
- 게임 준비에서 방장이 모임에서 합의한 플레이 순서를 위/아래 버튼으로 설정합니다.
- 턴은 `카드 뽑아 확인 → 던전에 놓기 / 카드+장비 가져오기` 또는 `패스`로 진행합니다.
- 한 명만 미패스 상태로 남으면 그 플레이어가 용사가 됩니다.
- 던전 성공 시 승리 토큰 1개, 2개면 승리. 첫 실패는 몬스터 목록 카드 빨간 테두리, 두 번째 실패는 탈락으로 표시합니다.
- 뽑은 몬스터는 다른 플레이어 UI에는 표시하지 않습니다. (공유 상태 기반의 모임용 구현이므로 개발자 도구 수준의 암호학적 비공개 저장은 아닙니다.)

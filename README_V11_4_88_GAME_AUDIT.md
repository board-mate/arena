# v11.4.88 게임 오류 점검

## 확인 및 수정

- 더 게임 온라인: 덱 소진 후 손패 없는 플레이어를 건너뛰어 잘못된 패배 방지.
- 더 게임 온라인: 남은 손패 수 때문에 최소 2장 규칙이 1장으로 줄어들던 턴 종료 조건 수정.
- 더 게임 로컬: 빈 손패 플레이어의 불필요한 턴(불꽃 타이머 포함)을 건너뜀. 덱이 남으면 최소 2장 조건 유지.
- 사무라이: 단독 다수 종류 외 두 종류의 합계 → 전체 조각 수로 승자 판정. 완전 동률 공동 승리.
- 판타지 왕국/그리스의 전설들: 잘못된 방 주소로 오류 화면 표시 후 사라진 netBadge에 접근하는 TypeError 수정.

## 규칙 근거

- NSV 공식 The Game Extreme 규칙서의 기본판 요약: https://www.nsv.de/wp-content/uploads/2024/04/TheGame_EX_GB.pdf
- Rio Grande/Hans im Glueck Samurai 원본 규칙서 미러: https://www.fgbradleys.com/wp-content/uploads/rules/Samurai-rules.pdf

## 검증 범위와 제한

29개 게임 페이지(온라인 21/솔로 8)의 실행 스크립트 40개 구문, JSON 메타데이터 4개, 정적 로컬 자산 경로 검사. 운영 브라우저에서 29개 초기 화면 점검. 방 ID 없는 온라인 화면의 안내 오류는 정상 진입 차단이며 실제 방 플레이 검증을 의미하지 않습니다.

새 회귀 테스트는 더 게임의 빈 손패/최소 장수/순차 되돌리기, 사무라이 합산/타이브레이커/공동 승리 사례를 실행합니다. 기존 캘리코/알림/이벤트 테스트도 함께 실행합니다.

전 게임의 전체 규칙, 카드별 효과와 여러 계정의 완주/재접속/동시 입력은 검증 완료가 아닙니다. 솔로 캘리코·캐스캐디아는 외부 iframe이며 이 저장소에서 엔진을 수정할 수 없습니다. 콘세르바스·에친스톤 등 자체 카드/변형 규칙 프로토타입은 실물 기본판과의 완전 일치를 보장하지 않습니다.

DB 변경 없음. 기존 저장 게임 데이터를 직접 수정하지 않음.

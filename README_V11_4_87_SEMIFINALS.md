# v11.4.87 — 준결승과 회원 목록

- 예선 A~D조 각 1·2위 → 8명 준결승(4명씩 2개 조) → 각 1·2위 → 4명 결승.
- 준결승 1조: A1/B2/C1/D2, 2조: A2/B1/C2/D1. 같은 예선 조 출신은 분리합니다.
- 예선 결과 수정 시 준결승·결승 초기화, 준결승 결과 수정 시 결승 초기화.
- 관리자 권한 관리에서 검색어를 비우고 ‘회원 목록 보기’를 누르면 전체 회원의 닉네임과 권한 상태를 확인하고 권한을 추가할 수 있습니다. 서버에서 대회 관리자 권한을 검사합니다.

## 적용 순서

1. 기존 이벤트 SQL 적용 환경에서 database/SUPABASE_EVENTS_V11_4_87.sql 실행.
2. 웹 파일 배포. 서비스워커 및 모듈 버전 11.4.87.

SQL은 기존 명단·예선 결과를 보존하고, 이전 방식의 결승은 이력에 원본을 보관한 뒤 초기화합니다. 이미 확정된 예선은 화면에서 준결승 대진을 생성하며 다음 저장 시 함께 저장됩니다. SQL 재실행은 이미 전환된 기록을 변경하지 않습니다.

## 수기 조 편성

운영 관리의 ‘조별 수기 편성’에 A~D 각 조 3~4명의 닉네임을 입력하면 입력 순서 그대로 대진표를 공개합니다. 중복 참가자는 거부하며, 다시 편성할 때 기존 경기 결과 초기화를 확인합니다. 무작위 시드 추첨도 계속 사용할 수 있습니다.

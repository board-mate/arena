# v11.4.86 — 시드 명단과 일반 명단

- 운영 화면에서 두 명단을 나란히 입력하고 총 인원을 확인합니다.
- 시드(룰마)를 각 조에 최대한 고르게 배치합니다. 4명이면 A~D조에 1명씩 배치합니다.
- 일반 참가자와 좌석은 무작위로 편성합니다. 총 12~16명 규칙은 유지됩니다.
- 생성된 대진표에는 시드 여부를 표시하지 않습니다.
- 기존 대회 기록은 일반 참가자로 읽으며, 새 기록은 시드 구분을 저장·복원합니다.
- Supabase의 기존 JSON 상태 저장 RPC를 그대로 사용하므로 신규 SQL 마이그레이션이 필요 없습니다.

검증: 전체 Node 테스트 25개 통과. 시드 수 0~전체 인원, 중복 이름, 그룹 정원, 백업 복원, 기존 SQL 저장·조회 호환 검증 포함.

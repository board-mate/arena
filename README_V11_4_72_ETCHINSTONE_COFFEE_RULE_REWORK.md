# BoardMate Arena V11.4.72
## Etchinstone + Coffee Roaster interaction / rule rework

기준 적용본: V11.4.70
V11.4.71을 적용하지 않았어도 이 패치만 적용하면 됩니다. V11.4.71의 에친스톤 수정 내용을 포함한 누적 패치입니다.

## 1. 에친스톤의 용들
- 조우 화면에서 마법사 카드 본체 클릭이 동작하도록 수정
- 도전 단계 카드 클릭 → 주문 역할 지정 후 행동 단계 진입
- 행동 단계 카드 클릭 → 주문 → 원소 → 증폭 → 예비 순환
- 역할 버튼/카드 본체 이벤트 충돌 방지
- 규칙서의 주문/원소/증폭/예비 역할 흐름 유지

## 2. 커피 로스터
### 온도 게이지 / 로스팅
- 수분 토큰 수에 따른 시작 위치 수정
  - 7~8개 = 6
  - 5~6개 = 7
  - 3~4개 = 8
  - 1~2개 = 9
- 빨간 구역을 연기 스택 위치인 10 / 12로 수정
- 빨간 구역에서는 로스트 레벨 +2
- 하드 원두는 예외로 레벨 0 원두가 됨
- 규칙에 없는 '로스팅 없이 턴 종료' 버튼 제거

### 왼쪽 로스팅 보드 즉시 효과
- 아무 토큰이나 비용으로 쓰던 기존 구현 제거
- 실물 보드의 토큰 종류 조건을 반영
  - 와일드 플레이버: 레벨 0/1 원두 또는 플레이버
  - +2 Drawing: Body
  - Redrawing 2: 플레이버
  - Drawing 5: Aroma
  - Cleaning Up: 플레이버
- 사용 토큰은 실제로 해당 액션 칸에 놓이며 로스팅 대상에서 제외
- 레벨 1 원두를 보드에 놓으면 로스트 카운터 -1
- Drawing 5에서 나온 수분은 자동 제거하지 않고, 제거 대상으로 고르지 않으면 백으로 복귀하도록 수정

### 플레이버 효과 / 오른쪽 보드
- Body(농축), Acidity(보존), Aroma(분산) 효과를 실제 플레이버 토큰 또는 Wild로 사용
- 사용한 플레이버 토큰을 오른쪽 보드의 적합한 칸에 직접 선택 배치
- 오른쪽 보드를 5개의 유니크 효과 획득 행으로 재구성
  - Roast-Level-3
  - Sweetness
  - Draw & Select
  - Redraw-2
  - Extra Tray
- 행의 두 칸이 모두 채워지면 해당 유니크 효과 토큰 획득
- Wild는 선택한 플레이버 효과의 종류로 오른쪽 보드에 배치

### 컵 테스트 전면 수정
- 기존 자동 최적 배치 제거
- 백에서 토큰을 직접 뽑고 컵 또는 트레이를 선택하는 방식으로 변경
- 수분 토큰은 컵 테스트에서 즉시 제거
- Roast-Level-3 / Sweetness 유니크 토큰을 컵의 지정 슬롯에 반영
- Extra Tray 획득 시 트레이 2칸 → 4칸
- Draw & Select 획득 시 2개 뽑아 1개 선택 과정을 2회 처리
- Redraw-2 획득 시 컵 완성 후 일반 토큰 2개를 골라 반환 → 3개 뽑기 → 2개 선택 적용
- Roast-Level-3 유니크 토큰은 재뽑기 대상에서 제외

### 채점
- Roast-Level-3 유니크 토큰을 로스트 합계와 스킬 점수에서 실제 레벨 3 원두처럼 계산
- Wild 플레이버 하나가 여러 플레이버 종류를 동시에 충족하던 오류 수정
- Wild 1개는 Body/Acidity/Aroma 중 1종만 대체 가능
- Wild는 Sweetness를 대체하지 않음
- 채점 화면 재렌더/세이브 복구 시 점수가 중복 저장되던 문제 수정

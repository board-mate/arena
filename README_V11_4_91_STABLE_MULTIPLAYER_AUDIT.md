# v11.4.91 정상 작동 분류 다인플 재점검

대상은 app.js의 gameInfo에서 tier가 없는 14개 게임이다. ALPHA/BETA 7개와 모든 솔로 게임은 이번 수정 대상에서 제외했다.

## 발견 및 수정

### 어콰이어

1. 합병 주식 처리 순서가 항상 0번 좌석부터 시작했다. 이제 합병을 일으킨 플레이어부터 시계 방향으로 진행한다. 남은 존속 주식이 부족할 때 교환 우선순위가 달라지는 문제를 해결한다.
2. 매각/교환 수량에 소수·NaN·무한대가 들어오면 주식과 현금이 잘못 계산될 수 있었다. 음이 아닌 안전한 정수만 허용한다.

### 프라코로

3. 에너지를 타입 요구와 무색 요구에 중복 계산했다. 예를 들어 불꽃 2개만으로 불꽃2+무색1을 충족하던 문제를 수정했다. 전체 요구량과 타입별 부족량을 함께 검사한다. 기존 무색 출목의 대체 처리 방식은 유지한다.
4. 자기 피해로 공격자만 HP 0이 되어도 턴이 넘어갔다. 즉시 상대 승리로 종료한다. 기존 동시 HP 0 판정은 유지한다.
5. 다음 상대 턴에만 적용되는 방어가 상대 기술 실패/0피해 시 사라지지 않았다. 해당 턴이 끝나면 소모된다.

## 실행 방법 및 한계

`npm test` 또는 `node --test tests/*.test.cjs`로 실행한다. PGlite가 필요하다.

- multiplayer-fixture는 HTML의 실제 함수와 상태 모델을 실행하고 네트워크 시작 부분을 제외한다. 게임 로직을 테스트에 복제하지 않는다.
- social-rules는 현재 저장소 SQL의 social 테이블/함수 전체를 메모리 DB에 올려 실행한다. 운영 DB에는 쓰지 않는다.
- 운영 브라우저는 BoardMate 회원 로그인 화면으로 이동하는 것을 확인했다. 이 세션에 Arena 회원 로그인이 없어 실제 다계정 방의 동시접속·완주·재접속은 검증하지 않았다.
- 위 항목이 통과해도 모든 카드 조합, 전체 규칙의 모든 예외, 통신 경쟁 상태를 전부 검증했다는 뜻은 아니다. 게임 tier는 변경하지 않았다.
- DB 함수/스키마 변경 없음. 기존 게임 저장 구조 유지. 이미 합병 처리 중인 어콰이어 큐의 순서는 바꾸지 않으며 다음 합병부터 적용한다.

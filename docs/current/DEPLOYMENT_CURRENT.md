# Deployment — v11.4.52

1. Upload the v11.4.52 integrated package (or Planet X patch) over the GitHub Pages repository.
2. Commit and push.
3. Reload BoardMate once so the v11.4.52 service worker activates.
4. Open an existing or new Planet X room and expand `내 기록지`.
5. Confirm the circular game board and circular record sheet both show sector **1 at the top**, with numbers increasing clockwise.

No Supabase SQL is required for v11.4.52. Existing Planet X rooms and private record data are compatible.

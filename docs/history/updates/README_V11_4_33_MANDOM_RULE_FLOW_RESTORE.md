# BoardMate Arena v11.4.33 — 맨덤의 던전 룰 흐름 복구

v11.4.32 통합 과정에서 `online-mandom.html`이 구버전(mandom-v1) 흐름으로 되돌아간 문제를 복구했습니다.

## 복구한 핵심 룰
1. 게임 시작 전 방장이 합의된 플레이 순서를 설정합니다.
2. 자기 턴에는 다음 3가지 중 하나를 선택합니다.
   - 몬스터 카드를 뽑아 자신만 확인한 뒤 던전에 놓기
   - 몬스터 카드를 뽑아 자신만 확인한 뒤 자기 앞에 가져오고 장비 토큰 1개 같이 가져오기
   - 패스
3. 살아있는 플레이어 중 1명을 제외한 전원이 패스하면 남은 1명이 즉시 용사가 됩니다.
4. 용사는 남아 있는 장비 토큰으로 던전에 쌓인 몬스터를 공략합니다.
5. 성공하면 승리 토큰 +1. 승리 토큰 2개면 승리합니다.
6. 첫 실패는 몬스터 목록 카드가 `뒤집힘 · 빨간 테두리` 상태가 됩니다.
7. 빨간 테두리 상태에서 다시 실패하면 그 플레이어는 탈락합니다.
8. 마지막 생존자가 되면 승리합니다.

## 함께 유지한 수정
- 용사의 검은 `고블린 ①/②`, `골렘 ①/②`처럼 같은 종류를 한 번에 무력화합니다.
- 게임 종료 시 대전 결과 제출 로직을 유지했습니다.
- 이전 mandom-v1 저장 상태도 `turnOrder`, `pendingDraws` 기본값을 보정해 열 수 있습니다.
- 서비스워커 캐시: `boardmate-shell-v11.4.33`

Supabase SQL 변경은 없습니다.

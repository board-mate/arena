# BoardMate Arena v11.4.46 · 행성 X 원형 기록지

## 변경 내용
- `내 기록지 > 섹터 메모`를 기존 사각 카드 목록에서 **원형 기록지**로 변경했습니다.
- 표준 모드는 12섹터, 전문가 모드는 18섹터로 자동 렌더링됩니다.
- 실물 기록지의 방향을 참고해 바깥쪽에 섹터 번호, 안쪽으로 `행성 X → 비어 보임 → 가스 구름 → 왜소행성 → 소행성 → 혜성` 순으로 기록 아이콘을 배치했습니다.
- 혜성 아이콘은 실제로 혜성이 존재할 수 있는 섹터에만 표시됩니다.
  - 표준: 2, 3, 5, 7, 11
  - 전문가: 2, 3, 5, 7, 11, 13, 17
- 각 아이콘은 기존과 동일하게 `미정 → × 없음 → ✓ 있음 → 미정` 순으로 전환됩니다.
- 기존 계정 비공개 기록 저장 RPC와 데이터 구조는 그대로 사용합니다. 기존 기록도 그대로 표시됩니다.
- 원형 기록지 중앙에는 모드/시작 계절과 기록 상태 안내를 표시합니다.

## 유지한 v11.4.45 변경
- 원형 게임 보드의 학술제/회의 표시
- 사용자 화면의 `논문` 용어
- 약자 범례 제거
- 참조표 최하단 배치

추가 Supabase SQL은 필요 없습니다. `online-planetx.html`, `sw.js`, `index.html`, `HANDOFF_VERSION.txt`를 덮어쓰고 강력 새로고침하면 됩니다.

## 적용 위치
1. 플레이어 카드: 좌측 색상 띠, 색 점, 색상명
2. 타임 트랙: 각 섹터에 플레이어 색 점. 현재 차례는 금색 외곽선
3. 가설 토큰: 테두리와 소유자 번호를 플레이어 색으로 표시
4. 가설 준비 상태: 이름 옆 색 점
5. 현재 진행/가설 배치/마지막 기회: 해당 플레이어 이름 앞 색 점
6. 공개 기록: 플레이어 행동 로그의 이름 앞 색 점
7. 최종 점수표: 플레이어 행 좌측 색상 띠와 색 점

# BoardMate Arena v11.4.52 — 행성 X 섹터 방향 통일

## 요청
행성 X 원형 게임판과 원형 기록지의 섹터 위치가 서로 달라 기록 대조가 불편했습니다. 두 화면 모두 맨 위(12시 방향)에 1번 섹터가 오도록 맞춥니다.

## 변경
- `online-planetx.html` 원형 기록지의 시작 각도를 기존 모드별 오프셋(Standard 105°, Expert 100°)에서 **0°**로 통일.
- 원형 게임판의 기존 좌표계(1번 = 12시, 이후 시계방향)와 원형 기록지가 동일한 방향을 사용.
- 표준 12섹터 / 전문가 18섹터 모두 동일 적용.
- 기록 데이터 자체(`priv.marks`)는 건드리지 않으며 화면 배치만 변경.
- 기존 네모 기록지와 게임 규칙/상태/DB는 변경 없음.

## 배포
- 서비스워커 캐시: `boardmate-shell-v11.4.52`
- Supabase SQL: 추가 없음

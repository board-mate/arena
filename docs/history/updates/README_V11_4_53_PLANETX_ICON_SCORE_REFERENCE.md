# BoardMate Arena v11.4.53 · 행성 X 아이콘/점수 참조표

## 변경
- 행성 X의 소행성 화면 기호를 `☄️`에서 `🪨`로 변경.
- 혜성은 `🌠`를 유지하여 기록지/게임판/논문 공개 토큰에서 혼동을 줄임.
- 맨 아래 `참조표`의 개체 표에 `정확한 논문` 점수 열 추가.
  - 소행성 2점
  - 혜성 3점
  - 가스 구름 4점
  - 왜소행성 4점(표준) / 2점(전문가)
- 참조표 하단에 논문 리더 보너스(+1) 및 행성 X 위치 점수 요약 추가.

## 호환성
- DB/RPC 변경 없음.
- 저장된 개체 값(`asteroid`, `comet` 등)은 그대로라 기존 진행방/기록과 호환.
- v11.4.52의 원형 섹터 방향 통일 유지.

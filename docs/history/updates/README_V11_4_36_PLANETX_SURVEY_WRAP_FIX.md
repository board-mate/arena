# BoardMate Arena v11.4.36 — 행성 X 개체 탐사 12→1 연속 범위 수정

기준: **v11.4.35 Planet X UI**

## 수정 내용

행성 X PVP의 `개체 탐사` 모달에서 시작 섹터를 변경했을 때, 현재 관찰 가능 하늘의 끝 섹터에서 다시 관찰 가능 하늘의 첫 섹터로 잘못 이어 붙이던 UI 로직을 수정했습니다.

예를 들어 표준 모드에서 관찰 가능 하늘이 `11, 12, 1, 2, 3, 4`라면 이제 다음처럼 올바르게 선택할 수 있습니다.

- 시작 11: `11`, `11→12`, `11→12→1`, `11→12→1→2` ...
- 시작 12: `12`, `12→1`, `12→1→2` ...
- 시작 1: `1`, `1→2`, `1→2→3` ...

반대로 관찰 가능 하늘이 `6, 7, 8, 9, 10, 11`일 때 `11→6`처럼 실제 태양계에서 연속이 아닌 범위가 생성되는 문제도 제거했습니다.

서버 RPC는 원래부터 `12→1`(전문가 모드에서는 `18→1`)을 연속 섹터로 검증하고 있었으므로 **Supabase SQL 변경은 없습니다.** 이번 패치는 클라이언트 범위 생성 UI만 수정합니다.

---

BoardMate Arena 개발을 이어가려고 합니다.

저장소는 https://github.com/board-mate/arena 입니다.
첨부 ZIP은 현재 저장소에 덮어쓸 통합 패치와 이전 작업 인수인계입니다.

먼저 `00_READ_ME_FIRST.md`와 `docs/HANDOFF_NEXT_CHAT.md`를 읽어 주세요.
**GitHub 현재본 + ZIP overlay 적용 상태를 새 기준본으로 취급**하고, ZIP의 파일을 GitHub 구버전으로 되돌리지 마세요.

이번 패치에는 이미 아래 3게임의 실제 온라인 구현이 들어 있습니다.
- 레지스탕스 아발론 5~10인
- 시크릿 히틀러 기본판 5~10인 (확장 없음)
- 한밤의 늑대인간 3~10인 (지정된 기본 역할 12종만)

따라서 이 3게임을 “아직 만들지 않은 게임”으로 취급하지 말고, 먼저 현재 구현을 검토/라이브 검증해서 오류가 있으면 수정해 주세요.

아발론과 한밤의 늑대인간은 게임 중 언제든 `🎭 이번 판 역할`에서 역할 이름과 수량만 볼 수 있어야 하고, 누가 무슨 역할인지/중앙 카드가 무엇인지는 종료 전 공개하면 안 됩니다.

비밀 역할·정책 카드·조사/야간 정보는 공용 state에 노출하지 않고 `boardmate_social_games.secrets` + 필터링 RPC 구조를 유지해야 합니다.

기존 미커밋 패치도 같이 들어 있습니다.
- 포크노바 1인플 관련 `pocketnova/index.html`, `pocketnova/js/ui.js` — 아직 실행 불가 문제 남음
- 캘리코 다인플 디자인 타일 4개 중 3개 선택 후 자기 퀼트의 위쪽 → 왼쪽 아래 → 오른쪽에 놓는 UI
- Power Grid Germany Supabase 패치 — 완전 자동화는 아직 남음

다음 작업 우선순위:
1) 업로드한 소셜 3종을 실제 Supabase에서 최소 인원으로 끝까지 플레이하며 E2E 검증/버그 수정
2) 포크노바 1인플 실행 불가 복구
3) 파워그리드 독일 맵 완전 자동화
4) 캘리코 다인플 패치 회귀검증

퀘스트는 만들지 않습니다. 시크릿 히틀러 확장판도 만들지 않습니다.

# BoardMate Arena 업데이트/롤백 기록

이 폴더는 CLEAN 배포본에서도 삭제하지 않는 장기 보관 영역입니다. 런타임에는 직접 필요 없지만, 과거에 정상 동작하던 버전을 추적하고 회귀(regression)가 생겼을 때 원인을 찾거나 롤백하기 위해 유지합니다.

## 보존 정책

- `updates/`: 버전별 변경 사항, 기능 추가/버그 수정 기록
- `verification/`: 당시 버전 검증 및 체크 결과
- `deployment/`: 버전별 GitHub 배포 메모
- `../../database/history/`: 과거 Supabase 변경/복구/검증 SQL
- 현재 실행에 필요한 코드는 프로젝트 루트와 `database/SUPABASE_CURRENT_UPDATE.sql`에 유지

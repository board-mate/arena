## 확인 포인트

1. `내 가설 배치 확정` 버튼이 보이지 않는지
2. 비공개 가설 선택 완료 후 자기 배치 차례에 자동 배치되는지
3. 내 기록지가 데스크톱에서 스크롤을 따라오지 않는지
4. 가설 토큰이 원형 보드의 외곽 → 중간 → 태양 방향 링으로 이동하는지
5. 뒷면 가설 토큰에 플레이어 색/번호가 보이는지
6. 공개된 천체가 A/G 같은 영문이 아니라 이모지로 보이는지
7. 보드 아래에 A/C/D/G/E/X 약자 범례가 작게 보이는지
8. 상태 갱신 후 스크롤 위치가 유지되는지

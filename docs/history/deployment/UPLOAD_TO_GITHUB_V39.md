## 확인 포인트

1. 원형 보드 중앙에 태양이 표시되는지
2. 원형 보드 섹터 사이에 방사형 경계선이 보이는지
3. 플레이어 위치가 원형 보드에 색 점으로 표시되는지
4. 가설이 작은 사각형으로 원형 섹터에 표시되는지
5. `내 비공개 조사 기록`이 게임판 바로 아래에 보이는지
6. `내 기록지`가 우측에서 참조표보다 위에 보이는지
7. 자동 상태 갱신 후 현재 페이지/내부 기록 스크롤 위치가 유지되는지

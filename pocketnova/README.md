# 포켓노바 (Pocket Nova) — 웹 구현 1차본

아크노바(Ark Nova) 룰을 기반으로 한 포켓몬 리스킨 보드게임 "포켓노바"의 웹 구현체입니다.
빌드 과정 없이 순수 HTML/CSS/JS(ES 모듈)로 작성되어 있어, 어떤 정적 호스팅(GitHub Pages 포함)에도
그대로 올리면 바로 동작합니다.

## 실행 방법

```bash
# 아무 정적 서버로 index.html을 서빙하면 됩니다. 예:
python3 -m http.server 8000
# 그리고 http://localhost:8000 접속
```

지금은 **로컬 hotseat 모드**로 동작합니다 — 한 화면/기기를 플레이어들이 돌려가며 사용합니다.
BoardMate Arcade의 공유 기능을 붙이는 방법은 아래 "온라인 멀티플레이어" 섹션을 참고하세요.

## 폴더 구조

```
index.html            진입점
css/style.css          타입별 컬러 카드 디자인 (도감 느낌의 종이 배경 + 물/불/풀/격투/에스퍼 컬러)
js/config.js           트랙 최대치, 수입 테이블, 건설비 등 숫자 설정 (⚠ 표시된 곳은 원본 물리 보드 확인 필요)
js/board.js             육각 타일 사파리존 로직 (지금은 원본 아님 — 아래 참고)
js/state.js              게임 상태 모델 + 셋업
js/engine.js            5개 행동(건설/포획/협회/도움/모험) 규칙 처리 + 휴식(Break) + 최종 점수 계산
js/abilities.js         동물/도움 카드 능력 자동 처리 (일반 패턴) + 수동 적용 폴백
js/network.js           멀티플레이어 어댑터 인터페이스 (LocalHotseatAdapter / ArcadeAdapter 스텁)
js/ui.js                 화면 렌더링 + 입력 처리
data/actionCards.js     건설/포획/도움/모험/협회 행동카드 5장 (I/II면)
data/cards-animals.js   물/에스퍼/불/격투/풀/화석 동물카드 127장
data/cards-sponsors.js  도움(스폰서) 카드 64장
data/cards-legendary.js 전설카드(보존 프로젝트) 32장
data/cards-finalscoring.js 중요한 물품(최종 점수) 카드 11장
test/smoke.mjs          헤드리스 엔진 테스트 (Node로 바로 실행 가능)
test/browser_smoke.mjs  Playwright 기반 UI 스모크 테스트
```

## 지금 바로 되는 것

- 2~4인 로컬 hotseat 진행, 셋업(초기 자금/손패/최종점수카드 2장) 자동 처리
- 5개 행동카드의 강도/슬롯 이동 규칙 (사용한 카드는 슬롯1로, 왼쪽 카드들은 오른쪽으로 밀림)
- 건설: 육각 지도 클릭으로 매점/파빌리온/기본 우리 건설 (인접 규칙 검증)
- 포획: 손패에서 동물을 우리에 배치, 매력도/보존/명성 획득 + 카드 능력 자동 적용(가능한 범위)
- 협회: 명성/파트너 동물원/대학 업무
- 도움: 도움 카드 내기 또는 휴식 트랙 전진으로 환전
- 모험: 덱에서 뽑기 / 필드에서 낚아채기
- X-토큰, 휴식(Break) 자동 트리거 (손패 제한, 일꾼 리셋, 필드 교체, 수입 지급)
- 종료 조건 체크(매력도-보존 점수 목표치 도달) + 최종 점수 계산

## 알아야 할 한계 (정직하게 적어둡니다)

1. **온라인 멀티플레이어 미구현.** Arcade의 "공유 기능"이 정확히 어떤 API인지(방/세션 방식, 전송
   방식 — WebSocket/Firebase/postMessage 등, 플레이어 식별 방식)를 몰라서 `js/network.js`의
   `ArcadeAdapter`는 아직 빈 스텁입니다. Arcade GitHub 저장소 링크, 이미 등록된 다른 게임의 소스,
   또는 관련 JS/문서를 공유해주시면 그 부분만 채워서 실제 온라인 동기화를 붙일 수 있습니다.
   그 전까지는 로컬 hotseat으로 완전히 플레이 가능합니다.

2. **사파리존(동물원) 지도는 원본이 아닙니다.** 업로드해주신 파일은 카드 시트들이고, 실제 물리
   동물원 맵 보드(칸 배치, 바위/물/보너스 위치)는 없었습니다. `js/board.js`의 `makeDefaultMap()`은
   플레이 가능하도록 만든 자체 제작 육각 지도입니다 (호수 하나, 바위 무더기, 보너스 칸 몇 개).
   실제 포켓노바 맵 데이터를 주시면 같은 형식(`{q,r,type}` 타일 목록)으로 교체만 하면 됩니다.
   또한 건물 모양은 실제 아크노바처럼 고정된 헥스 조각 모양이 아니라 "인접한 빈 칸 N개"로
   단순화했습니다.

3. **매력도→수입 테이블, 보존점수→목표치 테이블은 근사치입니다 (⚠ VERIFY).** 룰북 텍스트에는
   예시 몇 개만 나와 있고(매력도 7→수입 11 등, `js/config.js` 상단 주석 참고), 실제 물리 보드에
   인쇄된 정확한 표는 텍스트로 제공되지 않았습니다. 물리 보드를 보고 `js/config.js`의
   `appealIncome()` / `conservationTarget()` 표를 정확한 값으로 교체해주세요 — 엔진의 다른 부분은
   전혀 손댈 필요 없습니다.

4. **전설카드(보존 프로젝트) 32장의 정확한 3단계 보상 수치는 미확인입니다.** 어떤 아이콘/조건이
   필요한지(예: "물 타입 아이콘 필요", "풀 타입 포켓몬 방생")는 읽었지만, 작은 글씨의 정확한
   개수→점수 표는 확신할 수 없어 임시 공용 표(`DEFAULT_ICON_TIERS`/`DEFAULT_RELEASE_TIERS`)를
   씁니다. `data/cards-legendary.js`에서 카드별로 `tiers` 값만 실제 카드 보고 고치면 됩니다.

5. **도움(스폰서) 카드 64장은 능력 텍스트까지는 다 옮겼지만 자동화는 안 되어 있습니다
   (`abilityKey: 'manual'`).** 스폰서 카드는 원래 하나하나가 거의 유니크한 효과라 자동화 범위가
   가장 큽니다. UI에는 능력 텍스트가 항상 표시되니, 지금은 플레이어들이 직접 적용하는 방식으로
   진행하면 됩니다. 다음 단계에서 자주 나오는 패턴(수입형, 배치 보너스형 등)부터 자동화를
   넓혀갈 수 있습니다.

6. **동물 카드 127장 중 일부 능력만 자동 처리됩니다.** 뽑기/버리기/돈 획득/매력도 획득류의 흔한
   패턴(`js/abilities.js`)은 자동 적용되고, 나머지는 카드 텍스트를 보여주고 플레이어가 직접
   반영합니다 (정직한 스코프 선택이며 버그 아님).

7. **최종 점수 카드 중 "학습 장치"(연결/커버리지 체크)와 "포케 도감"(오른쪽 플레이어 비교)은
   자동 계산되지 않습니다** — 보드 연결성/좌석 순서 로직이 필요해서 이번 1차본에서는 제외했고,
   최종 집계 때 수동으로 더하면 됩니다.

8. **풀 타입 "핫삼" 카드의 매력도 수치가 원본 이미지에서 잘려 확인 불가**했습니다
   (`data/cards-animals.js`에 note로 표시).

9. **기부 비용 표, X-토큰 액션에서 어떤 행동카드를 슬롯1로 보낼지 고르는 부분** 등 몇몇 세부
   규칙은 단순화되어 있습니다 (코드 내 주석 참고).

## 카드 데이터 정확도에 대해

카드 시트 PDF들은 텍스트 레이어가 없는(그림으로 렌더링된) 파일이라 `pdftotext`로 추출이 안 되고,
이미지를 직접 읽어서 옮겨 적었습니다. 숫자/능력 텍스트는 최대한 정확히 옮겼지만, 사람이 이미지를
보고 옮긴 데이터이니 실제 카드와 다른 부분이 있다면 `data/` 폴더의 해당 파일에서 값 하나만 고치면
바로 반영됩니다.

## 온라인 멀티플레이어 (다음 단계)

앱 전체가 네트워크를 직접 건드리지 않고 `js/network.js`의 어댑터를 통해서만 상태를 주고받도록
설계했습니다. 그래서 Arcade 쪽 API를 알려주시면:

1. `ArcadeAdapter`의 방/세션 읽기, 채널 열기, `publish()`/`onRemoteUpdate()` 구현만 채우고
2. `createNetworkAdapter()`가 Arcade 환경을 감지하면 `ArcadeAdapter`를, 아니면 지금처럼
   `LocalHotseatAdapter`를 반환하도록 분기하면 됩니다.

필요한 정보: Arcade GitHub 저장소 링크 / 이미 등록된 다른 게임의 소스 / 관련 문서나 JS 코드 일부.

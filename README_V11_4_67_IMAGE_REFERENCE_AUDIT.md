# BoardMate Arena V11.4.67 — 기존 게임 이미지/룰 레퍼런스 점검 패치

기준 버전: **V11.4.66 ALPHA — Pan Am V2**

이번 패치는 업로드된 기존 게임 이미지 자료를 현재 구현과 대조한 뒤, 이미지에서 바로 확인할 수 있고 기존 저장 상태를 깨뜨리지 않는 항목만 우선 반영했습니다.

## 반영 사항

### 1. 맨덤의 던전
- 업로드된 장비 이미지 기준으로 **횃불(Torch)** 판정을 수정했습니다.
- 기존: 공격력 `3 미만`만 무력화
- 수정: 공격력 `3 이하` 무력화
- 따라서 오크(공격력 3)도 횃불로 무력화됩니다.
- 화면 설명 문구도 같은 기준으로 수정했습니다.

### 2. 어콰이어
업로드된 호텔 체인 가격표/보드 이미지를 기준으로 수정했습니다.

- 저가 체인: `Worldwide`, `Sackson`
- 중가 체인: `Festival`, `Imperial`, `American`
- 고가 체인: `Continental`, `Tower`

기존 코드에서 잘못 분류되어 있던 `Tower`, `Worldwide`, `Imperial`의 가격 등급을 수정했습니다.

또한 내부 저장 키는 그대로 유지하면서 화면에 표시되는 타일 좌표를 실물 보드 방식으로 변경했습니다.
- 내부 상태: `A1 ~ L9` 유지
- 화면 표시: `1A ~ 12I`
- 기존 진행 중인 게임 상태와의 호환성을 유지하기 위해 저장 데이터 구조는 변경하지 않았습니다.

### 3. 파워그리드
업로드된 인원별 세팅표를 기준으로 **2인 플레이를 활성화**하고 관련 상수를 수정했습니다.

- 지원 인원: `2~6인`
- 2인 사용 지역: 3개
- 2인 무작위 제거 발전소: 8장
- 2인 보유 가능 발전소: 4개
- 2인 Step 2 진입: 도시 10개
- 2인 게임 종료 트리거: 도시 21개

기존 발전소 덱 코드의 `plug/socket` 분리 방식을 유지하기 위해 2인 제거 8장은 현재 엔진 구조에 맞춰 `2 + 6`으로 적용했습니다.

### 4. 캘리코
업로드된 4개 플레이어 보드 이미지를 프로젝트 내부 자산으로 추가했습니다.

- `assets/calico/boards/blue.webp`
- `assets/calico/boards/green.webp`
- `assets/calico/boards/purple.webp`
- `assets/calico/boards/yellow.webp`

기존에는 플레이어 보드 배경을 외부 MyAutoma 주소에서 불러왔지만, 이제 **보드 배경은 BoardMate Arena 로컬 파일을 우선 사용**합니다.
타일 이미지는 기존 외부 자산 + CSS fallback 구조를 그대로 유지했습니다.

## 이미지 대조는 했지만 이번 패치에서 보류한 항목

### 돌팔이 약장수
업로드된 가마솥 이미지를 확인한 결과 현재 코드의 `GOLD_OF`, `POINTS_OF`, 루비 위치가 실제 보드를 단순 근사한 구조임을 확인했습니다.
실물 트랙은 단순 0~35 선형식으로 바꾸기 어려워 **전체 가마솥 칸 인덱스/코인/VP/루비 매핑을 먼저 데이터화한 뒤 별도 패치**하는 편이 안전합니다.

### 사무라이
업로드 이미지에는 실제 보드 지형/배치 정보가 있지만 현재 게임은 간략화된 육각 그리드를 사용합니다.
이미지만 교체하면 클릭 좌표와 게임 판정이 어긋나므로 **실제 보드 좌표 데이터 재구성**이 필요합니다.

### 엘도라도
업로드 이미지에는 실제 지형 타일이 있으나 현재 구현은 추상 헥스 코스입니다.
실제 타일을 적용하려면 각 타일의 헥스 좌표, 연결부, 회전 방향을 데이터화해야 하므로 별도 맵 패치로 분리합니다.

### 캐스캐디아
업로드 이미지에는 여러 야생동물 점수 카드가 포함되어 있으나 현재 자동 점수 엔진은 A 세트 중심입니다.
B/C/D 점수카드는 이미지별 조건을 코드로 각각 구현하고 테스트해야 하므로 별도 룰 패치 대상으로 남겼습니다.

# BoardMate Arena V11.4.73
## Project L 멀티플레이 + Conservas 솔로 추가

기준 적용 흐름: **V11.4.70 + V11.4.72**

이번 패치는 새 게임 2종을 추가합니다.

- 다인플: **Project L**
- 1인플: **Conservas**

사용자가 제공한 규칙서의 규칙/구성/흐름을 구현 기준으로 사용했으며, 규칙서 이미지 자체를 사이트 자산으로 넣지 않았습니다.
새 PNG/JPG/WebP asset 추가는 없습니다.

## 1. Project L 멀티플레이

파일: `online-projectl.html`

### 구현 범위
- 2~5인 방 생성/온라인 동기화
- 플레이어별 레벨 1 + 레벨 2 시작 조각
- 흰색/검정색 퍼즐 행
- 미완성 퍼즐 최대 4개
- 차례당 정확히 3액션
- 가져가기
- 재순환
- 업그레이드
- 조각 배치
- 마스터 액션(차례당 1회)
- 조각 회전 / 뒤집기
- 퍼즐 완성 시 사용 조각 회수 + 보상 조각 획득 + VP 적립
- 검정 퍼즐 덱 소진 시 종료 트리거
- 현재 라운드 완료 후 최종 1라운드
- 마무리 터치: 추가 배치 1개당 -1VP
- 최종 점수와 동률 처리
- 방 취소 투표 / 결과 반영

### 인원수
기본 구현은 **2~5인**입니다.
공식 2.5 규칙서는 6인도 안내하지만 6인 게임에는 Ghost Piece 또는 Phoenix 확장 중 하나가 필요하다고 명시하므로, 이번 기본 게임 구현에서는 5인까지 열었습니다.

### 퍼즐 데이터 주의
업로드된 규칙서는 전체 흰색 32개/검정색 20개 퍼즐의 모든 개별 오목 영역 데이터를 제공하지 않습니다.
따라서 V11.4.73에서는 규칙서의 퍼즐 구조/레벨/보상/점수 체계를 이용한 **BoardMate 절차 생성 퍼즐 세트**를 사용합니다.
게임 규칙 엔진은 공식 기본 규칙을 따르되, 개별 퍼즐 타일 데이터는 공식 실물 세트의 1:1 복제가 아닙니다.

## 2. Conservas 1인플

파일: `solo-conservas.html`

### 구현 범위
- **1월 시나리오** 우선 구현
- 시작 자금 €10
- 시작 바다 주머니: 정어리 5 / 가리비 5 / 물 10
- 첫 보트: 2장 중 1장 선택
- 보트/업그레이드 공개 시장
- 바다 단계
  - 기본 5개 토큰 뽑기
  - 각 보트/외해에 라운드마다 1회 배치
  - 보트 어획량만큼 어획, 나머지는 심해
  - 외해는 전부 심해
  - 주머니 부족 시 일반 공급처의 물로 보충
  - 물까지 부족하면 남획 패배
- 육지 단계
  - 어획한 물고기로 시장 주문 판매
  - 어획한 물고기로 업그레이드 구입
  - 돈으로 보트 구입
- 1월 시장은 각 행을 왼쪽 → 오른쪽 순으로 채움
- 판매 주문 완료 시 물고기 1개는 시장 표시용으로 남고 나머지만 일반 공급처로 반환
- 하루의 끝
  - 남은 어획 물고기 정리
  - 보트에 어획된 물 토큰은 주머니로 반환
  - 공개 보트/업그레이드 보충
  - 보트 유지비
  - 심해의 같은 어종 2개 이상이면 `n-1` 산란
  - 심해 토큰을 주머니로 반환
- 마지막 라운드 후 자금 + 지속 가능성 목표 판정
- 로컬 자동 저장

### 현재 시나리오 목표
BoardMate V11.4.73의 1월 구현 목표:
- 최종 자금 €40 이상
- 바다 정어리 4개 이상
- 바다 가리비 4개 이상

### 카드/시장 데이터 주의
업로드된 규칙서에는 18장 보트, 27장 업그레이드, 12개월 시장의 모든 개별 카드/보드 데이터가 전체 목록 형태로 수록되어 있지 않습니다.
따라서 V11.4.73은 **1월 핵심 규칙을 실제 플레이 가능하게 만드는 ALPHA**이며,
보트/업그레이드/시장 주문의 개별 데이터 일부는 BoardMate 구현 세트입니다.
이후 카드/월별 자료를 추가로 확보하면 공식 데이터에 맞춰 교체할 수 있습니다.

## 3. Supabase 적용

Project L은 새 멀티플레이 game id `projectl`을 사용하므로 웹 파일만 올리기 전에 Supabase SQL 업데이트가 필요합니다.

1. Supabase Dashboard → SQL Editor
2. `SUPABASE_PROJECT_L_V1.sql` 전체 실행
3. 성공 후 GitHub에 웹 파일 업로드

SQL은 다음을 추가/갱신합니다.
- `projectl` 게임 카탈로그 허용
- Project L 방 생성
- 2~5인 제한
- turn seat 추적 (`state.current`)
- 취소 투표 지원
- 평점 game constraint

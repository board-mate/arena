# BoardMate Arena v11.4.40 — 행성 X 가설 트랙/기록지 개선

## 변경 사항

### 1. `내 가설 배치 확정` 제거

가설 단계에서 이미 `비공개 선택 완료`로 내용을 확정했기 때문에, 별도의 두 번째 확인 버튼을 없앴습니다.

- 모든 플레이어가 비공개 선택을 마치면 기존 순서대로 배치 단계가 진행됩니다.
- 자기 배치 차례가 되면 선택 내용이 자동으로 공개 보드에 배치됩니다.
- 개체 종류는 기존과 동일하게 비공개 상태를 유지합니다.

### 2. 내 기록지 sticky 해제

기존 데스크톱 CSS의 `position: sticky`를 제거했습니다. 따라서 내 기록지가 화면을 따라다니지 않습니다.

### 3. 실물판형 가설 트랙

원형 태양계 보드 안에 3개의 가설 링을 두었습니다.

- 외곽 링: 신규 가설
- 중간 링: 1단계 전 가설
- 안쪽 링: 검증 직전 가설

기존 서버의 `depth` 1~3 값을 그대로 시각화하기 때문에 게임 로직이나 DB 구조는 바뀌지 않습니다.

가설이 같은 섹터/같은 깊이에 여러 개 있으면 원주 방향으로 조금씩 벌려 겹침을 줄입니다.

### 4. 가설 제출자 표시

뒷면 가설 토큰은 `플레이어 색 + 좌석 번호`로 표시합니다. 보드 아래에 좌석 번호와 플레이어 이름 범례를 함께 표시합니다.

공개된 가설은 천체 이모지로 바뀌며, 제출자 번호는 작은 배지로 유지합니다.

### 5. 천체 이모지

원형 보드와 상세 가설 표시에서 영문 한 글자 대신 다음 이모지를 사용합니다.

- ☄️ 소행성
- 🌠 혜성
- 🪐 왜소행성
- ☁️ 가스 구름
- ⬚ 비어 보임
- ✦ 행성 X

영문 약자는 기록용 작은 범례로만 남깁니다.

## 기존 기능 유지

- 혜성 메모는 허용 섹터에만 표시
- 맞은편 섹터 안내 유지
- 내 비공개 조사 기록은 원형 보드 바로 아래 유지
- 상태 갱신 시 스크롤 복원 유지
- 새 Supabase SQL 없음

# BoardMate Arena V11.4.70
## Map Rework — BASE V11.4.66

이 패치는 **V11.4.68 / V11.4.69를 적용하지 않은 V11.4.66 기준**으로 바로 덮어쓸 수 있습니다.
중간 패치는 필요하지 않습니다.

## 작업 원칙
사용자가 제공한 게임 이미지/ZIP은 **게임 구조·보드 모양·구성 요소를 이해하기 위한 참고자료**로만 사용했습니다.
이번 패치에는 참고 이미지를 사이트에 직접 넣지 않았고, **새 WEBP/PNG/JPG asset을 추가하지 않았습니다.**
지도 표현은 HTML/CSS/SVG/JS로 재구성했습니다.

## 변경 내용

### 1. 팬암 (`online-panam.html`)
- 기존 도시/항로/팬암 확장 판정은 그대로 유지
- 단색에 가까웠던 지도 배경을 세계지도 형태의 SVG 보드로 개선
- 대륙/해양 윤곽과 라벨을 추가해 실제 팬암 보드의 세계지도 느낌을 강화
- 항로 클릭 영역과 기존 게임 상태 구조는 변경하지 않음

### 2. 사무라이 (`online-samurai.html`)
- 실제 플레이 보드 화면 자체를 개선
- 기존 육각 좌표와 조각 배치/포획 로직은 그대로 유지
- 각 육지 셀을 묶어 혼슈·규슈·시코쿠·홋카이도 형태의 코드 기반 해안선 배경을 자동 생성
- 바다 셀을 더 옅게 처리하고 섬 윤곽/라벨을 추가
- 2/3/4인 기존 저장 상태와 호환되도록 `G.cells` 구조는 변경하지 않음

### 3. 엘도라도 (`online-eldorado.html`)
- 신규 게임의 기본 맵을 기존 긴 `arena` 프리셋 대신 **4개 모듈을 조립한 custom 맵**으로 시작하도록 변경
- 정글/마을/강/산/캠프 지형을 이미지 없이 CSS 질감으로 개선
- custom 맵의 각 모듈 뒤에 보드 타일처럼 보이는 코드 기반 배경을 표시
- 기존 프리셋 맵과 이전 저장 게임은 그대로 유지되므로 기존 방 호환성 보존
- 기존 맵 설정 버튼에서 프리셋/조립 맵 변경 기능도 계속 사용 가능

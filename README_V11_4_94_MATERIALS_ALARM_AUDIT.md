# v11.4.94 자료 반영 및 알림 점검 (2026-11-05)

## 반영 내용

### 알림
- 내 차례 알림을 처음 보내지 못하면 같은 차례의 다음 확인 때 다시 시도합니다.
- 새 방·게임 시작 알림도 해당 상태가 유효한 동안 재시도합니다.
- 이미 전달한 같은 차례가 오래된 방 응답에 다시 나타나도 중복 알림하지 않습니다.
- Service Worker 전송, 브라우저 Notification 대체 경로, 권한 거부, 초기 실패 후 재시도, 중복 응답, 겹친 조회를 실제 알림 모듈을 실행하는 자동 테스트로 확인합니다.
- 실제 운영 페이지에서 시스템 알림 권한이 필요하고 테스트 버튼이 비활성 상태임을 확인했습니다. 사용자가 권한 허용과 테스트에 동의했으나, 컴퓨터 제어가 브라우저 주소 확인 실패로 중단되어 실제 OS 알림 도착은 확인하지 못했습니다.
- 앱/브라우저 완전 종료 후 Web Push를 받는 기능은 이번 변경에 포함하지 않습니다.

### 프로젝트 L
- 제공된 실물 퍼즐 시트 2장(이미지 목록 51, 67)에서 5×5 격자를 추출했습니다.
- 새 게임은 하양 32개·검정 20개의 정확한 모양, 인쇄 점수, 보상 조각을 사용합니다.
- 조각 색상을 자료에 맞췄습니다. 새 게임 상태 버전은 2이며 기존 진행방 퍼즐은 변경하지 않습니다.
- 2/3/4인 검정 퍼즐 12/14/16개 선택과 기존 마스터 액션 회귀를 검증합니다.

### 돌팔이 약장수
- 새 게임에 실물 냄비 이미지의 53칸 구매력·승점·루비 표를 적용했습니다. 같은 구매력이 반복되는 칸도 별도 이동 칸으로 처리합니다.
- 6면 보너스 주사위의 1점 면 2개를 반영했습니다.
- 새 게임에서는 빈 플라스크가 다음 라운드에 무료 충전되지 않으며 루비 2개로 충전해야 합니다.
- 제공된 냄비 참조 이미지와 11개 칩 이미지를 표시합니다. 이미지가 없는 칩은 기존 숫자 표시를 유지합니다.
- 구형 진행방의 위치 숫자 의미를 보존하기 위해 기존 냄비 표와 라운드 전환을 유지합니다.
- 여전히 세트 1 기반 ALPHA 게임이며 쥐 마커·점쟁이 카드 및 다른 성분책 세트는 구현하지 않았습니다.

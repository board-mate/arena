# 2026-10-30 게임 점검

## 수정

- **캘리코:** 4인 게임에서도 저분산 옵션을 켤 수 있어 타일이 108장 대신 72장만 생성되고, 보드가 비어 있는데 시장이 소진됐다. 두 저분산 설정을 2인용으로 제한하고 게임 생성 시 인원도 검사한다. 기존 2인 방의 보드·토큰·설정을 변경하지 않는다.
- **Project L:** 마스터 액션 도중 퍼즐을 완성하자마자 조각과 보상을 받아 같은 액션에서 재사용할 수 있었다. 모든 배치가 끝나고 마스터 종료를 눌렀을 때 완성 퍼즐들을 정산한다. 마스터 도중 퍼즐 가져오기·행 재순환·업그레이드도 함수와 화면 양쪽에서 막는다.
- **에어 랜드 & 씨:** 공수 다음 턴에 카드를 뒷면으로 내면 공수 효과가 이후 턴까지 남았다. 앞면/뒷면 모두 다음 턴에 효과를 소모한다. 상대 차례에는 소모하지 않고 새 공수 효과는 유지한다.

DB 변경은 없다. 저장된 과거 행동과 이미 받은 보상은 다시 계산하지 않는다. 기존 4인 게임에서 잘못 생성된 72장 주머니를 108장으로 바꾸는 소급 마이그레이션은 포함하지 않는다.

## 검증

- 전체 자동 테스트 **86개 통과**: 기존 77개와 이번 회귀 9개.
- 캘리코 실제 엔진으로 2·3·4인 게임의 모든 보드를 채우고 최종 점수까지 계산. 고정 난수 시드로 재현하며 네트워크 저장은 호출하지 않는다.
- 캘리코 인쇄 가장자리 포함 그룹, 같은 연결 영역의 중복 토큰 차단, 다섯 도형 고양이의 여섯 방향 회전, 기존 토큰 보존 확인.
- Project L 마스터 중 조각·보상 재사용 차단, 다른 행동 차단, 종료 후 정산, 마무리 터치의 보상·재사용 제한 확인.
- 에어 랜드 & 씨 공수 효과 소모와 상대 턴/재획득 확인.
- 온라인 21개·솔로 8개, 총 **29개 운영 페이지** 초기 진입 확인. ReferenceError·TypeError·SyntaxError를 확인하지 못했다. 방 주소 없이 접속한 온라인 게임의 진입 안내는 정상 차단으로 분류했다.
- 로그인된 진행 중 캘리코 2인 방에서 보드·손패·현재 차례 표시 및 콘솔 오류 없음 확인. 플레이 행동은 하지 않았다.

# BoardMate Arcade v10 — 설치 / 운영 메모

npm / 터미널 / 빌드 없이 GitHub Pages에 그대로 올리는 버전입니다.

## 이번 v10 핵심

- 진행 중 게임에 **게임 취소 투표** 추가
  - 참가자 누구나 `게임 취소` 버튼으로 동의/철회
  - **현재 방 참가자 전원이 동의한 순간** 방 상태가 `cancelled`로 변경
  - 취소 게임은 승패/ELO에 반영하지 않음
- 캘리코 / 캐스캐디아 1인플은 직접 재구현하지 않고 **외부 GitHub Pages 구현을 활용**
  - 캘리코: MyAutoma Calico
  - 캐스캐디아: Cascadia Game
  - BoardMate wrapper 상단의 `← 홈`, `1인플`, `새 탭` 버튼만 제공
- 포켓노바 1인플은 이번 버전에서 제외
  - 업로드된 원본은 보관
  - 추후 아크노바의 공식 1인플 전용 규칙을 기준으로 별도 구현 예정
- 캐스캐디아 온라인에 **참고표** 추가
  - 지형 5종 / 동물 5종 아이콘과 이름
  - 한 차례 진행 순서
  - 현재 온라인 초심자 동물 점수표
- 캐스캐디아 재접속/다른 참가자 화면의 `Cannot read properties of null (reading 'habitats')` 오류 수정
  - 현재 플레이어가 선택지의 타일/동물을 가져간 뒤 배치 중인 동안 빈 선택지가 생겨도 다른 참가자 화면이 깨지지 않음
  - `배치 중…` 자리표시자로 표시 후 턴 종료 시 다시 보충

## 1. GitHub Pages 업데이트

1. 이 폴더의 파일을 기존 저장소에 전부 덮어쓰기
2. 기존 `config.js`의 Supabase URL / anon(publishable) key는 유지
3. GitHub Pages 배포가 끝난 뒤 브라우저에서 한 번 새로고침

## 2. Supabase SQL — v10에서는 다시 실행 필요

v8에서 바로 올라오는 경우 게임 취소 투표용 DB 함수/테이블이 없으므로 반드시 실행하세요.

Supabase → `SQL Editor` → `New query` → `supabase.sql` 전체 복사 → `Run`

추가되는 주요 항목:

- `boardmate_rooms.status = cancelled` 지원
- `boardmate_room_cancel_votes`
- `boardmate_get_cancel_status(...)`
- `boardmate_set_cancel_vote(...)`

기존 회원, 방 기록, 레이팅 데이터는 유지하도록 작성되어 있습니다.

## 3. 게임 취소 방법

진행 중인 온라인 게임 오른쪽 아래의 `게임 취소` 버튼을 누릅니다.

- 한 명이 동의해도 게임은 계속 진행
- 다른 참가자가 동의하면 현재 동의 수가 표시됨
- 동의한 사람은 취소 확정 전까지 철회 가능
- 전원이 동의하면 즉시 게임 취소 화면으로 전환
- 취소된 게임은 승패/ELO 미반영

접속이 끊긴 참가자도 방 멤버인 동안에는 전원 수에 포함됩니다. 따라서 정말 전원 동의를 요구하는 방식입니다.

## 4. 캘리코 / 캐스캐디아 1인플

BoardMate에서 자체 복제품을 관리하지 않습니다.

- `solo-calico.html` → `https://myautoma.github.io/games/calico/index.html`
- `solo-cascadia.html` → `https://cascadiagame.github.io/`

iframe이 브라우저 정책 때문에 막히는 경우 상단 `새 탭 ↗` 버튼으로 바로 열 수 있습니다.

## 5. 캐스캐디아 온라인 수정

캐스캐디아는 한 사람이 선택지에서 타일+동물을 가져간 뒤 `서식지 배치 → 동물 배치`를 끝내기 전까지 선택지 한 칸이 잠시 비어 있습니다.

기존 버전은 다른 참가자가 그 순간 상태를 받아 렌더링하면 빈 타일(`null`)에서 `habitats`를 읽으려 하면서 화면이 중단됐습니다.

v10은:

- 빈 선택지 null-safe 렌더링
- 구버전/불완전 상태 기본 보정
- 방장이 초기 상태를 아직 만드는 중이면 `게임 준비 중…` 표시
- 현재 플레이어가 가져간 칸은 `배치 중…`으로 표시

하도록 수정했습니다.

게임 오른쪽에는 `📌 캐스캐디아 참고표`가 있습니다.

- 지형: 산악 / 삼림 / 초원 / 습지 / 하천
- 동물: 곰 / 엘크 / 연어 / 매 / 여우
- 초심자 동물 카드: 같은 종류 무리 1마리=2점, 2마리=5점, 3마리 이상=9점
- 남은 솔방울 1개=1점

## 6. 포켓노바

온라인 포켓노바 베타는 그대로 유지합니다.

1인플 포켓노바 카드는 이번 버전에서 제거했습니다. 추후 추가할 때는 AI 대전이 아니라, 말씀하신 대로 **아크노바 1인플 전용 규칙을 포켓노바 엔진에 맞춰 구현**하는 방향으로 진행합니다.

## 7. 기존 기능 유지

- 미니게임: 펜토리니 / Yahtzee
- 온라인 자동 저장 / 재접속 / 접속 끊김 표시
- 방장 강퇴(대기실)
- 관리자 회원 정지 / 해제 / 영구 퇴출
- 마이페이지 비밀번호 변경
- 비공개 ELO + `#1~#5 / 🥇 / 🥈 / 🥉`
- 게임 종료 안내 화면
- 방 제목 미입력 시 자동 생성
- 룰북 PDF는 ZIP에 포함하지 않음

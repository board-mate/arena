# BoardMate Arcade v7 — 설치 / 운영 메모

npm / 터미널 / 빌드 없이 GitHub Pages에 파일을 그대로 올리는 버전입니다.

## 1. GitHub Pages

1. 이 폴더의 파일을 기존 GitHub 저장소에 전부 덮어쓰기
2. `Settings → Pages → Deploy from a branch`
3. `main` / `/ (root)` 선택
4. 기존 `config.js`의 Supabase Project URL / anon(publishable) key는 유지

## 2. v7에서는 supabase.sql을 다시 실행하세요

Supabase → `SQL Editor` → `New query` → v7의 `supabase.sql` 전체 복사 → `Run`

기존 회원/방/기록을 지우지 않고 다음 항목을 추가합니다.

- 실시간 / 턴제 방 모드
- 진행 중인 방의 현재 차례 회원 저장
- 다인플 목록의 `내 차례` 표시
- 캐스캐디아 온라인 방 / 게임별 레이팅
- 방 제목을 비워 두었을 때 자동 제목 생성

## 3. Board Game Arena처럼 비동기 턴제

방 만들 때 두 가지 중 하나를 선택합니다.

- `⏳ 턴제` — 모두 동시에 접속할 필요 없음. 행동마다 자동 저장되고, 방 목록에서 현재 차례와 `내 차례`를 표시합니다.
- `⚡ 실시간` — 기존처럼 함께 접속해서 빠르게 진행합니다.

턴제도 게임 규칙은 동일합니다. 자기 차례가 아닌 사람은 게임을 열어 구경할 수 있지만 행동 버튼은 비활성화됩니다.

현재 GitHub Pages + Supabase 구조에서는 사이트를 완전히 닫은 사람에게 푸시 알림을 보내지는 않습니다. 다인플 목록에 들어왔을 때 `내 차례`를 확인하는 방식입니다.

## 4. 리코셰 삭제

리코셰는 메인 화면과 라우터에서 제거했습니다. 예전 `boardmate_results`의 리코셰 기록은 DB에 남아 있을 수 있지만 사이트에서는 더 이상 사용하지 않습니다.

## 5. 인게임 티어 표시

게임 화면과 방 대기실에서 긴 `브론즈 / 실버 / 골드` 글자를 없앴습니다.

- 브론즈: `🥉`
- 실버: `🥈`
- 골드: `🥇`
- 게임별 ELO 1~5위: `#1` ~ `#5`

ELO 숫자는 여전히 공개하지 않습니다.

## 6. 캘리코 v7

온라인 캘리코 보드를 육각형 실제 인접 관계로 다시 만들었습니다.

- 22개 헝겊 배치칸 + 중앙 디자인 타일 3개
- 홀수/짝수 줄을 단순 사각 그리드처럼 붙이지 않고 실제 육각 인접 좌표 사용
- 바깥쪽 인쇄 헝겊 가장자리 추가
- 가장자리 헝겊도 색/무늬 연결 점수 계산에 포함
- 디자인 타일은 주변 6개의 육각칸을 검사
- 기존 자동 저장 / 재접속 / 게임별 레이팅 유지

이전 버전에서 시작한 캘리코 방은 보드 구조가 달라서 v7에서 이어가지 않고 새 방을 만드는 것이 안전합니다.

## 7. 캐스캐디아 온라인 추가

`online-cascadia.html`을 추가했습니다.

현재 온라인판은 제공받은 한국어 규칙서의 **공식 초심자 변형**을 기본으로 사용합니다.

- 2~4인
- 선택지에 서식지 타일 + 동물 토큰 4쌍
- 각자 정확히 20턴
- 과잉 공급 4개 자동 교체 / 3개 선택 교체
- 솔방울로 조합 분리 또는 동물 토큰 교체
- 육각형 생태계에 서식지 타일 인접 배치
- 해당 동물 그림이 있는 빈 서식지에만 동물 배치
- 초심자 동물 점수: 같은 종류 무리 1마리 2점 / 2마리 5점 / 3마리 이상 9점
- 각 지형의 가장 큰 광역 지형 계산
- 인원수에 따른 광역 지형 상위권 보너스
- 남은 솔방울 1개당 1점
- 자동 저장 / 재접속 / 턴제 / ELO

고급 동물 점수 카드 A~D 전체는 이후 단계에서 추가할 수 있습니다.

## 8. 게임 종료 안내

온라인 게임이 끝나면 결과와 함께 다음 이동 버튼이 표시됩니다.

- `홈으로`
- `다인플 목록`
- `방으로 돌아가기`

대상: 마스크맨 / 어콰이어 / 캘리코 / 캐스캐디아 / 더 게임 / 노터치 크라켄

## 9. 방 제목 자동 생성

방 만들 때 제목을 비워도 됩니다.

예:

`보드왕의 캘리코 한 판`

처럼 `닉네임 + 게임명`으로 자동 생성합니다.

## 10. 룰북 PDF

ZIP에는 룰북 PDF를 넣지 않습니다. 용량 절약을 위해 게임 코드만 배포합니다.

## 11. 기존 관리자 / 계정 기능

v6의 기능은 그대로 유지합니다.

- 관리자 회원 정지 / 정지 해제 / 영구 퇴출
- 마이페이지 비밀번호 변경
- 관리자 비밀번호 초기화
- 이메일 없는 닉네임 + 비밀번호 계정
- 1인플 로컬 자동 저장
- 다인플 자동 저장 / 재접속 / 접속 끊김 표시

최초 관리자 지정:

```sql
select public.admin_set_boardmate_admin('내닉네임', true);
```

비밀번호 초기화:

```sql
select public.admin_reset_boardmate_password('회원닉네임', '1234');
```

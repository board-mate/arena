# BoardMate Arena v11.4.35 — 행성 X PVP 사용성 패치

기준본: **BoardMate Arena v11.4.34 Planet X PVP**

이번 버전은 게임 규칙/DB 구조를 바꾸지 않고 `online-planetx.html`의 사용성을 보강한 패치입니다. v11.4.29 HOTFIX 계열과 v11.4.33 맨덤 수정, v11.4.34 행성 X PVP 서버/RPC 구조는 그대로 유지합니다.

## 변경 사항

### 1. 게임 중 참조표 추가

우측 `참조표` 카드에 현재 모드에 맞는 기본 개체 규칙을 표시합니다.

- 혜성: 가능한 섹터 번호
- 소행성: 각 소행성이 최소 1개의 다른 소행성과 인접
- 왜소행성: 표준/전문가 개수 및 전문가 6섹터 띠 규칙
- 가스 구름: 진짜 빈 섹터 인접 규칙
- 행성 X: 왜소행성과 비인접, 탐사/섹터 지정에서 비어 보임
- 진짜 빈 섹터: 표준 2 / 전문가 5
- 액션 시간 비용 참조표

### 2. 자동 동기화 때 스크롤 위치 유지

기존에는 상태 동기화 렌더링이 발생하면 긴 화면에서 사용자가 보고 있던 위치가 위쪽으로 이동할 수 있었습니다.

수정 내용:

- 전체 페이지 `window.scrollX / scrollY` 저장 후 렌더링 뒤 복원
- 플레이어 줄, 타임 트랙, 공개 기록, 시작 정보, 비공개 조사 기록의 내부 스크롤도 별도 복원
- 준비 상태 polling은 값이 실제로 달라졌을 때만 재렌더링
- 가설 준비 polling도 값이 실제로 달라졌을 때만 재렌더링

따라서 단순 1.8초/1.9초 polling 때문에 화면이 계속 다시 그려지는 현상을 줄였습니다.

### 3. 영문 개체/연구 용어 한국어 표시

GM 카탈로그의 원본 데이터는 영문이지만 클라이언트 표시 단계에서 한국어로 변환합니다.

- `Asteroid(s)` → `소행성`
- `Comet(s)` → `혜성`
- `Dwarf Planet(s)` → `왜소행성`
- `Gas Cloud(s)` → `가스 구름`
- `Planet X` → `행성 X`
- `Empty Sector` → `진짜 빈 섹터`

공개 회의 정보의 `topic/rule`, 개인 주제 조사 결과, 시작 정보, 이전에 저장된 영문 조사 기록 표시에도 변환을 적용했습니다.

연구 규칙 문장은 카탈로그에서 사용하는 모든 규칙 템플릿을 한국어 문장으로 변환합니다. 169개의 고유 rule 문자열을 정적 검증했습니다.

### 4. 섹터 메모 한글화

기존 `A / C / D / G / E / X` 축약 표시 대신 다음 이름을 직접 표시합니다.

- 소행성
- 혜성
- 왜소행성
- 가스 구름
- 비어 보임
- 행성 X

클릭 상태는 기존과 동일하게 `미정 → × 없음 → ✓ 있음 → 미정` 순환입니다.

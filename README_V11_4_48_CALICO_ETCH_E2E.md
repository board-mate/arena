# BoardMate Arena v11.4.48 — Calico / Etchinstone recovery patch

## 요청 반영

- **포켓몬 미니마**: Arena UI/배포 런타임에서 제거 상태를 재검증했고 남아 있던 전용 스타일 잔재를 제거했습니다. `프라코로 포켓몬`은 별도 게임이므로 유지합니다.
- **에친스톤의 용들**: 1인플 홈/목록에 다시 노출하고 `solo-etchinstone.html`로 진입하도록 복구했습니다. 기존 로컬 자동 저장/이어하기 동작을 유지합니다.
- **Calico 진행 중 게임 복구**
  - 모바일 포함 우측 상단 빈 육각 칸의 클릭/터치 우선순위를 보강했습니다.
  - 루미(3칸 일자) 조건을 새 타일 배치 직후 다시 판정하며, 인쇄 가장자리 타일을 포함한 상단/우측 그룹도 판정합니다.
  - `현재 보드 조건 다시 검사` 버튼을 배치/시장/턴 종료 단계에 추가했습니다. 이미 진행 중인 방에서도 놓친 고양이/단추 후보를 현재 보드 전체에서 재검색하여 토큰 단계로 복구합니다.
  - 재검사 시 기존 턴 토큰 표시를 덮어쓰지 않고 병합합니다.
  - v11.4.47 및 이전 Calico 방 상태는 `gameId=calico-pvp` 호환 경로로 그대로 로드하며 보드/턴/라운드를 초기화하지 않습니다.
- **게임 취소**: Calico 상단에 항상 찾기 쉬운 `게임 취소` 버튼을 추가하고 공용 만장일치 취소 패널을 직접 엽니다. `multi-common.js?v=11.4.48`로 캐시를 우회합니다.

## 데이터/DB

이번 패치는 **새 SQL이 필요하지 않습니다.** Calico 진행 상태 스키마와 `VERSION=12`를 유지해 현재 진행 중인 방을 그대로 이어갈 수 있게 했습니다. 공용 게임 취소 RPC는 기존 BoardMate 취소 기능을 그대로 사용합니다.

## E2E 검증

`tests/v48_calico_etch_e2e.py`를 headless Chromium으로 실행했습니다.

- Calico 데스크톱 1400px / 모바일 390px에서 새 게임 시작
- 손패 선택 → 우측 상단 `0,4` 타일 배치
- 루미 후보 자동 검출 → 루미 토큰을 우측 상단 타일에 실제 클릭 배치
- 실제 인쇄 가장자리 타일을 포함하는 상단 우측 루미 그룹 검출
- 기존 진행 게임처럼 루미를 놓친 상태 → `현재 보드 조건 다시 검사` → 토큰 단계 복구
- 복구 전후 활성 좌석/라운드/플레이어 수 유지
- 구버전 Calico 상태 수신 → 보드/턴/라운드 무초기화 확인
- 에친스톤 새 게임 → 로컬 자동 저장 → 런타임 복귀 화면 → 저장 게임 이어하기
- 공용 취소 컨트롤 마운트 → Calico 상단 버튼에서 취소 패널 열기
- 모든 위 흐름에서 브라우저 page error 0건

수정 대상 외 `online-*.html` / `solo-*.html` 게임 파일은 v11.4.47과 바이트 단위 동일함을 확인했습니다.

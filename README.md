## 🌌 최근 핵심 업데이트

### 🔭 행성 X를 찾아서

- **게임판과 기록지 방향 통일** — 둘 다 **12시 방향이 1번 섹터**, 이후 시계방향으로 증가합니다.
- **원형 ↔ 기존 네모 기록지 전환** — 같은 기록 데이터를 공유하며 선택한 레이아웃은 브라우저에 기억됩니다.
- **🌑 소행성 표기 통일** — 조사 기록, 논문, 기록지, 참조표까지 동일한 이모지를 사용합니다.
- **논문 교차 검증 공개 기록 강화** — 틀린 논문은 `플레이어 · 섹터 · 개체 · 해당 개체가 없음 · 패널티 +1`까지 공개 기록에 표시합니다.
- **진행 중 구형 게임 로그 복구** — 예전 `틀린 논문 패널티 시간 +1`만 남은 행도 공개 논문 상태가 남아 있으면 상세 교차 검증 기록으로 합쳐 보여줍니다.
- **행성 X 찾기 인접 섹터 안내** — 예: `X 후보 = 9`이면 **왼쪽 8번 / 오른쪽 10번**에 무엇이 있는지 선택하라고 명확히 표시합니다.
- **최종 정답 전체 공개** — 게임 종료 후 모든 섹터의 실제 개체, **행성 X 위치**, X 양옆 섹터의 실제 개체를 한 번에 확인할 수 있습니다.
- **참조표 보강** — 논문 점수와 리더 보너스/행성 X 발견 점수를 하단 참조표에서 바로 확인할 수 있습니다.

### 🔔 알림 / 웹 내 차례 표시

- `🔔 알림 설정`에서 브라우저 알림 권한, 알림음, 진동, 테스트 알림을 설정할 수 있습니다.
- 내 차례가 되면 웹 브라우저 탭 제목이 **`🔔 내 차례 · 게임명`** 으로 바뀝니다.
- 페이지 복귀, 포커스 복귀, 온라인 재연결 때 상태를 즉시 다시 확인합니다.
- 같은 턴에서 알림이 계속 반복되지 않도록 턴 서명을 로컬에 기억합니다.

> **중요:** 현재 OS 알림은 브라우저/PWA가 실행 중일 때의 **best-effort 알림**입니다.  
> 브라우저/PWA를 완전히 종료한 상태에서도 확실히 울리는 알림은 아직 구현되지 않았습니다. 그 기능은 **Web Push 구독 + 서버/Edge Function 발송**이 필요합니다. 웹에서는 시스템 알림이 누락되더라도 탭의 `🔔 내 차례` 표시를 사용할 수 있습니다.

## 🧯 롤백 원칙

BoardMate는 “예전에는 됐는데 새 패치 이후 깨짐”을 추적할 수 있어야 합니다.

- 과거 업데이트/검증/배포 문서는 **오래됐다는 이유로 삭제하지 않습니다.**
- 정상 배포마다 Git 커밋과 가능하면 버전 태그를 남깁니다.
- 장애가 나면 DB를 먼저 되돌리지 말고 **코드 정상 태그와 현재 태그를 비교**합니다.
- DB 역적용은 데이터 손실 가능성이 있으므로 `database/history/`를 읽고 별도로 판단합니다.
- 새 패치에서 공용 파일(`app.js`, `multi-common.js`, `alarm.js`, `sw.js`)을 바꾸면 다른 게임 회귀 테스트를 반드시 합니다.

자세한 원칙은 [`docs/history/ROLLBACK_GUIDE.md`](docs/history/ROLLBACK_GUIDE.md)를 참고하세요.

4. 진행 중 게임을 패치할 때는 방을 초기화하거나 서버 상태를 임의로 변환하기보다 **표시 호환/점진적 마이그레이션**을 우선합니다.

# BoardMate Arena v11.4.37 — 행성 X 플레이어 색상 구분

최신 통합 릴리스는 **v11.4.37**입니다.

v11.4.36의 행성 X 개체 탐사 연속 범위 수정과 기존 게임 패치를 그대로 유지하면서, 행성 X PVP에서 플레이어를 색상으로 즉시 구별할 수 있도록 UI를 개선했습니다.

- P1 파랑 / P2 빨강 / P3 노랑 / P4 초록 고정 색상
- 상단 플레이어 카드에 색상 띠·색 점·색상명 표시
- 타임 트랙에 각 플레이어의 실제 위치를 색 점으로 표시
- 현재 차례 플레이어의 타임 트랙 색 점은 금색 외곽선으로 강조
- 가설 토큰 소유자를 해당 플레이어 색상으로 표시
- 가설 준비 상태, 현재 진행 안내, 마지막 점수 기회, 최종 점수표에도 동일 색상 적용
- 공개 기록에서 플레이어 이름으로 시작하는 행동 로그는 해당 플레이어 색상으로 표시
- 기존 v11.4.36 게임 상태와 호환 (상태/DB 스키마 변경 없음)
- **추가 Supabase SQL 없음**

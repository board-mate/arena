# BoardMate Arena v11.4.39 — 행성 X 게임판 중심 UI

최신 통합 릴리스는 **v11.4.39**입니다.

v11.4.38의 연구 주제 제목, 혜성 기록 제한, 원형 맞은편 안내를 그대로 유지하면서 실제 보드게임판처럼 핵심 정보가 한 화면에 모이도록 행성 X PVP 배치를 다듬었습니다.

- **내 비공개 조사 기록을 원형 게임판 바로 아래로 이동**
- 조사 결과는 최신순으로 즉시 쌓이며 별도 스크롤 영역에서 계속 확인
- 오른쪽 상단에 **내 기록지(시작 정보 + 섹터 메모)**를 배치해 참조표/공개 기록보다 먼저 보이도록 변경
- 원형 보드에 섹터 경계선, 중앙 태양, 플레이어 시간 위치 색 점, 가설 미니 토큰 추가
- 상세 섹터 카드는 필요할 때 펼치는 방식으로 변경해 원형 게임판이 중심이 되도록 정리
- 기존 자동 상태 갱신 시 스크롤 위치 복원 로직 유지
- DB/방 상태/localStorage 구조 변경 없음

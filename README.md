# BoardMate Arena v11.4.36 — 행성 X 개체 탐사 연속 범위 수정

최신 통합 릴리스는 **v11.4.36**입니다.

v11.4.35의 행성 X PVP 사용성 패치를 그대로 유지하면서, `개체 탐사` 범위가 태양계 번호 경계에서 잘못 생성되던 문제를 수정했습니다.

- 표준 모드 `12 → 1` 연속 탐사 가능
- 전문가 모드 `18 → 1` 연속 탐사 가능
- 관찰 가능 하늘의 끝에서 첫 칸으로 임의 점프하는 잘못된 범위 제거 (`11 → 6` 같은 범위)
- 기존 참조표/스크롤 보존/한국어 번역 유지
- 기존 프라코로/판타지 왕국/맨덤 수정 유지
- **추가 Supabase SQL 없음**

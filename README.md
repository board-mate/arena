# BoardMate Arena v11.4.38 — 행성 X 기록지 / 주제 제목 / 원형 보드 보강

최신 통합 릴리스는 **v11.4.38**입니다.

v11.4.37의 행성 X 플레이어 색상 구분과 기존 게임 수정 사항을 유지하면서, 행성 X PVP의 실제 플레이에 필요한 정보 표시를 보강했습니다.

- 주제 조사 A–F 선택 전에 **주제 제목(대상 천체)** 표시
- 주제 제목만 공개하고 실제 논리 규칙은 연구 실행 후 해당 플레이어에게만 공개
- 섹터 기록지의 **혜성 버튼을 혜성이 있을 수 있는 섹터에만 표시**
  - 표준: 2, 3, 5, 7, 11
  - 전문가: 2, 3, 5, 7, 11, 13, 17
- 기존 상세 섹터 보드 위에 **원형 태양계 방향판** 추가
- 모든 섹터에 `↔ 맞은편 N`을 표시해 정반대 힌트를 바로 적용 가능
- 표준 모드 정반대 = +6섹터, 전문가 모드 정반대 = +9섹터
- 기존 가설 트랙, 교차 검증, 타임 트랙, 플레이어 색상 UI 유지

# BoardMate Arena v11.4.40 — 행성 X 실물판형 가설 트랙 UI

최신 통합 릴리스는 **v11.4.40**입니다.

v11.4.39의 원형 태양계 게임판과 스크롤 복원 기능을 유지하면서, 가설 표시와 기록지 동작을 실물 게임판에 더 가깝게 다듬었습니다.

- **`내 가설 배치 확정` 버튼 제거**: 비공개 가설 선택을 완료하면 자기 배치 차례에 자동으로 보드에 놓입니다.
- **내 기록지 sticky 해제**: 데스크톱에서도 스크롤을 따라오지 않고 원래 위치에 머뭅니다.
- **가설 토큰을 원형 보드 안쪽 트랙에 직접 배치**: 바깥(신규) → 중간 → 태양 쪽(검증 직전)으로 전진합니다.
- **누가 놓았는지 즉시 식별**: 비공개 가설 토큰은 플레이어 색 + 좌석 번호로 표시합니다.
- **언제 놓였는지 위치로 식별**: 바깥/중간/안쪽의 3단계 링으로 가설의 경과 단계를 확인할 수 있습니다.
- **태양계 게임판의 천체 표시는 영문 약자 대신 이모지**를 사용합니다.
- 기록용 영문 약자는 작은 범례로만 유지합니다: `A=소행성 · C=혜성 · D=왜소행성 · G=가스 구름 · E=비어 보임 · X=행성 X`.
- 기존 `captureScroll()` / `restoreScroll()` 로직은 유지합니다.

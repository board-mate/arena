## v11.4.57 핵심 변경

- **행성 X 진행 중 게임의 구형 공개 기록 복구**: v11.4.55 이전/당시 상태에서 `상현 · 틀린 논문 패널티 시간 +1`처럼 남아 있는 줄을, 저장된 공개 논문 토큰 상태를 이용해 `교차 검증 · 상현 · 섹터 9 🌑 소행성 논문 틀림 → 해당 섹터에는 🌑 소행성 없음 · 패널티 시간 +1` 형태로 화면에서 합쳐 표시합니다. 기존 서버 게임 상태는 수정하지 않습니다.
- **행성 X 찾기 인접 섹터 안내**: X 후보 섹터를 고르면 왼쪽/오른쪽 인접 섹터 번호가 즉시 표시됩니다. 예: X=9 → 왼쪽 8번 / 오른쪽 10번.
- **행성 X 최종 정답 공개**: 게임 종료 후 12/18개 모든 섹터의 실제 개체를 표시하고, 행성 X 위치와 왼쪽/오른쪽 인접 섹터의 실제 개체를 별도 요약합니다.
- **알림 안정성 개선**: 이미 내 차례인 상태로 페이지에 처음 들어온 경우도 해당 턴을 한 번 알리고, 같은 턴에서는 중복 알림을 막습니다. 탭 복귀/포커스/온라인 복귀 시 즉시 다시 확인합니다.
- **브라우저 탭 내 차례 표시**: 턴 기반 게임에서 내 차례이면 탭 제목 앞에 `🔔 내 차례 ·`가 붙습니다. 시스템 알림 권한이 없어도 웹에서 확인할 수 있습니다.
